拾刻把 NAS 上的视频和图包放进一个媒体库。挑选目录或标签后连续浏览，边看边留下喜欢的内容、打标签、移入回收站，让收藏慢慢变得有条理。

- **快速整理** — 在选定范围内连续查看，随手移入回收站并撤销，也支持多选整理。
- **视频与图包** — 视频播放，图包纵向拼接、横向翻页、缩放与续读。
- **独立标签** — 视频和图包分别管理标签，按目录、标签和关键词查找。
- **私人部署** — Docker 部署到自己的 NAS，Android App 通过个人口令连接。
- **日常维护** — 各目录扫描进度、回收站、管理数据备份与恢复。

## 使用

在 NAS 配置媒体目录并启动 Docker 服务，在 Android 安装拾刻，填写服务地址、端口和个人口令即可连接。
