## 固定的任务与内容

品类是个人短视频浏览与整理 App，主力设备为 Android。用户来首页观看当前收藏、随机切换、通过标签找回内容；需要整理时能快速删除并撤销。每屏以一条视频为主角，不添加宣传口号、统计面板或额外保留状态。

三版均处于日常浏览、暂停的同一个主状态，共享视频、文件名、标签、媒体属性、时间和随机位置。入口也相同：浏览/整理、筛选、更多（归档和回收站）、全屏、标签编辑、删除、上一条/播放/下一条，以及底部浏览、视频库、标签、设置。排布不同是视觉方案的一部分，没有改变功能范围与主要任务。

`content.json` 是共用事实和演示数据的唯一来源；`build.mjs` 在生成时填入三份独立结构与样式，没有用同一模板更换主题色。重建候选运行 `node build.mjs`；再使用 oil-ui-pro 的 `build_explorer.py manifest.json --force` 重建对比页。

## 标杆与取舍

看过的官方真实画面保存在 `references/`，只作设计研究，不作为页面素材。

- Immich 的移动端多选画面：缩略图紧密相接，视频时长贴于画面角落，方便扫描内容；本项目保留内容优先原则，但日常浏览以单视频为主。
- Immich 的选中项使用面积明显的着色层和圆形勾选，批处理状态不会与普通浏览混淆；留给后续 P2 的批量操作。
- Immich 的底部操作面板把删除和上传变成带文字的大目标；保留带名称的高风险动作，去掉本项目不需要的上传与分享。
- Immich 页面中深色底和浅色线图标把亮度留给照片；A 沿用这种明暗关系，使用薄荷色播放键和独立文件题注，不复制品牌蓝色与网格结构。
- Ente 的移动端画面以中性色承托彩色内容，页面头部短，照片很早进入视野；三版均不设大品牌区和介绍段。
- Ente 的时间分组和窄缝网格支持回找，底部导航使用稳定位置；本项目保留稳定的四个一级入口，不引入相册、人物或回忆模块。
- Ente 的浮动圆角导航与多张卡片形成消费相册的语气；B 选择有边距的单张影像与宋体题注，C 选择直角操作轨，避免三版都落入同一圆角模板。

Immich 最初访问的旧 overview 页面有资源错误，未用作有效参考。最终参考为其官方文档中的移动端操作截图。

## 方向卡

共用调性：观看时安静、边缘精确、密度适中，一屏一个对象；不使用拟物道具与装饰动画。内容本身提供颜色。品类常见的是黑灰底加蓝色强调，本轮用暗灰/薄荷、纸白/草木绿、浅灰绿/钴蓝三套关系，差别也落实到构图、字体与控件形状。

| | A · 静夜 | B · 留白 | C · 明快 |
| --- | --- | --- | --- |
| 北极星 | 让视频留在光里，界面退到暗处 | 像翻私人画册，安静看清每段收藏 | 把观看和整理放进清楚有力的面板 |
| 引擎 | 观看时周边退暗的显示面板 | 私人影像的装裱、题注关系 | 小型播放设备的明确操作分区 |
| 骨架 | 连续深色舞台，操作贴右边，时间紧贴画面 | 有边距的影像、竖向循环说明、独立题注和水平操作行 | 视频与竖向操作轨并列，下方宽播放键 |
| 字体 | 微软雅黑标题与正文，Bahnschrift 数字 | 宋体标题，微软雅黑正文，Georgia 数字 | 黑体标题与控件，Consolas 数字 |
| 色彩 | #111519 底、#B9E7DA 强调、#263731 标签底 | #FAF8F3 底、#53664A 强调、细灰绿边线 | #EDF2ED 底、#2355CD 强调、#243C44 描边 |
| 主视觉 | 深色画面中完整显示的同一条视频 | 留边画框中完整显示的同一条视频 | 直角窗口中完整显示的同一条视频 |
| 图标/控件 | 1.7px 线图标、圆播放键、轻量浮动操作 | 同义线图标、细线圆播放键、下划线标签 | 同义线图标、直角标签和按钮、较粗边界 |
| 主动放弃 | 大卡片、霓虹光晕、满屏文字覆盖 | 深色观影壳、过多圆角容器 | 柔和阴影、浮动胶囊导航 |

共同复用视频素材是有意保持内容相同，差异检验主要看构图、字体、色彩和控件。A 为推荐方案：适合以随机观看为主，视觉噪声低，播放和删除仍可触达。B 在浅色阅读场景更像个人收藏册；C 对控件区的表达最直接。最终由用户选择，不预设已选定。

## 本轮完成与边界

- 只做静态首屏；没有接真实数据、没有实现业务交互、没有响应式和动效。播放按键、筛选、标签等在本轮用于比较外观，不能据此验收功能；原始横竖示例视频可从素材文件单独播放。
- 选定后进入 P2，再做完整 HTML 交互、关键状态和各流程；本轮没有推进 Flutter 或服务端。
- 按技能的首屏探索范围，每版一张截图自检，未启动独立评审、打分、录屏或全量取证。
- 检查了完整视频比例、中文显示、题注与按钮位置、底部导航和对比度。B/C 初次截图的低对比文字已调深；最终三版均无控制台错误、横向溢出、图片加载错误或默认做法提示。
- 没有额外宣传文案，初稿已按任务压缩，未再删除必要的对象信息与主动作。
- 未新增正式产品 DESIGN 规范；此处方向卡待选择后成为 P2 的设计基线。

`screenshots/` 保存三版最终实际截图和检查报告，`screenshots/comparison/` 保存同尺寸并排预览。对比页使用技能自带生成器，没有另写比较工具，也没有修改其模板。
