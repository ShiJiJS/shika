# 视频与参考来源

## 原型内的视频

- 原文件：MDN Interactive Examples 的 flower.mp4，发布于其 `cc0-videos` 目录。
- 下载地址：https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4
- MDN 用法说明：https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video
- 本地横版：`flower-landscape.mp4`，保留下载的原文件。
- 本地竖版：`flower-portrait.mp4`，从横版中心裁切为 9:16，输出 360 × 640、无音轨，以便比较竖版显示；不是另一段独立拍摄的视频。
- 两张 JPG 封面均取各自视频约 1.2 秒处。没有将参考产品的图片用作本项目的视频封面。
- 三个方向都使用同一个竖版及封面；横版保留供单独观看与后续 P2 使用。
