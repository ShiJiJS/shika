# 严格归并

生成或修正标准标签时读取。标准层只做有依据的提取、中文化和归并；识图模型本身也可能误识别，来源可追溯不代表视觉事实已经人工核实。

## 事实适配

从原始记录逐条提取以下结构，保留原目录路径恢复证据。只读取用户允许进入上下文的文本；严格隐私时程序在本地提取，映射缺失不向助手回显内容。

```
[{"video_id":"V000001","facts":[
  {"source_kind":"directory","source_ref":"旧目录索引.json","field":"category","pointer":"/category","raw":"舞蹈","status":"affirmed"},
  {"source_kind":"raw_tag","source_ref":"原答.json","field":"appearance_tags[0]","pointer":"/prediction/appearance_tags/0/tag","raw":"白色丝袜","status":"affirmed"}
]}]
```

每条事实的 `source_ref` 相对于 facts.json，`pointer` 为原始 JSON 的确切位置；脚本核对该位置的值与 raw 完全相同。映射字段 field 表示稳定的语义字段，数组下标仅用于 pointer 定位。已有示例中的 field 可沿用，但不能据此放宽候选状态。状态肯定性仍需从原记录语义核对，字段存在本身不等于肯定。

允许来源：`directory`（原目录的明确类别）、`raw_tag`（原模型肯定标签）、`manual`（已有人工确认）。候选/不确定记录保持原状态，尤其不能仅因没有 status 字段就把角色候选标 affirmed。图片模型单边候选、摘要猜测、文件宣传名、归档目的地均不能冒充原目录事实。目录索引丢失时用已验证的旧路径映射恢复；无法恢复就留空。

对女性外观需原条目或原记录明确主体归属；多人物且归属不清则留候选。从记录里的不确定措辞排除冲突，摘要不能用于新增行为、角色或特征。

## 映射与类别

规则必须同时匹配 `source_kind`、`field` 和 `raw` 原词，值为零个或多个 `{group,tag}`。禁止宽泛子串匹配、默认兜底类别、根据相邻词拼出新事实。

```
{"rules":[
  {"source_kind":"directory","field":"category","raw":"舞蹈","outputs":[{"group":"内容分类","tag":"舞蹈"}]},
  {"source_kind":"raw_tag","field":"appearance_tags[0]","raw":"白色丝袜","outputs":[{"group":"袜类","tag":"白丝"}]}
]}
```

建议维度：类型（真人/动画/混合）、画风（二维/三维/混合）、内容分类、作者、角色、行为、袜类、穿搭、女性外观。实际保留维度由用户现有目标决定。

- 原目录的行为类别只有明确同义关系才映射。性行为不自动等于“纯啪”；自慰不自动等于“单人自慰”；对话不等于剧情；姿势不等于写真；作者分组不是内容类别。
- 作者标签来自确定的作者目录段，保留作者署名。不要给管理目录名加作者标签。
- 白色丝袜可归白丝，浅色袜、白色棉袜、浅色过膝袜不自动等于白丝；颜色和材质均不清时留空。其他颜色/长度归并也不得扩大原意。
- 角色只有已有肯定识别才能进入标准层。英文角色名转明确中文名；译名需作品信息消歧，不按相似姓名猜。没有可信中文映射就保留原始候选并暂缓标准角色标签。
- 标准标签用中文；作者原署名可保留。原始英文、分数、候选和不确定性始终留在原始层。
- 有歧义/冲突的字段空置并记原因，不生成用于搜索的“待确认”标签。不依据衣着/宣传词判定实际年龄，也不借此删改原始信息。

## 输出与验证

```
python "$skill_dir/scripts/catalog.py" normalize --facts facts.json --rules rules.json --output standard.json --protected protected.json
```

先运行 protect 保存完整原始输入散列。随包脚本核对原始字段值与散列后，精确匹配规则并保存字段级依据、待核项及同名标签去重；规则的语义正确性仍需对原文本审核。不会擅自生成语义映射。输出路径必须是新版本，同时生成同名 MD。

核对每个输入编号恰好一次、每个标准标签有来源、原始文件散列前后相同，输出逐视频新增/撤销差异。本地模型或当前助手编写的 rules 仍需逐项检查是否仅中文翻译/同义归并；脚本无法证明两个自然语言词语等义，不能把通过结构校验宣称为语义正确。不确定项留空属于完成状态的一种，不为凑满内容类别回填推测词。同步使用标准 JSON，原始标签文档保持原样。
