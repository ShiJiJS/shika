# 常见问题核对表

技能维护、归并规则变化或纠正历史错误时读取。这里列出归并与同步需要防止的错误；执行规则分别以主流程和参考文件为准。

| 问题 | 当前处理与验收点 |
| --- | --- |
| 根据互动、人物数量或集合语境补行为 | 只接受原字段肯定标签及明确原目录类别；对话→剧情、互动→纯啪、器具→自慰均不能自动推出 |
| 把性行为泛化成纯啪，或自慰泛化成单人 | 保留原意，不扩大标签；空类别不回填猜测，不为每个视频强加一个类别 |
| 只抄“按作者分类/综合合集” | 管理目录不变内容标签；真实作者段可提取署名，原内容目录通过稳定编号恢复 |
| 迁移后旧目录丢失 | 单独保护原目录索引与移动清单；新归档目录不替代原目录依据 |
| 图片候选或角色候选被升格 | 保留候选状态；affirmed 要有原记录肯定语义，中文角色名结合作品消歧；脚本原字段核对不代表语义正确 |
| 服饰/颜色宽泛归并、男性特征混进女性标签 | 白棉袜不归白丝，中长发不强归长发；女性归属不明留候选 |
| 基于宣传/服饰词猜年龄并删信息 | 不据此作实际年龄结论；原始数据保留，标准层不确定就留空 |
| 原始结果被覆盖或丢候选分数 | 原始保护散列、原答拒绝覆盖；候选、完整数值矩阵与原文留在原始层 |
| 数量对了但绑定到错误视频 | 原编号＋迁移依据＋新路径/大小＋当前 UUID 逐项匹配，扫描和分页完整，应用前检查实例/挂载/元数据快照 |
| 用旧 UUID 导入、删除数据库重建 | 从当前扫描重建对应表，旧 UUID 只作审计；保留播放/回收站历史 |
| replace 覆盖人工标签 | 按成功回执计算本流程自有标签差量；缺归属证据时不撤销 |
| 当前视频无引用就删标签定义 | 查询全部状态及播放轮次引用；空定义清理单列授权，不由普通同步自动做 |
| 软件修好了但旧清单后台再次导入 | 更新当前标准文件与导入清单、副本；旧任务与历史规则不能继续回写 |
| 图片/标签通过日志进入助手上下文 | 图片权限和标签权限分别记录；只输出编号、计数与错误类型；本地失败不切线上 |
| 在另一电脑找不到原项目路径 | 技能包内相对引用，运行路径由本机配置和逻辑根目录绑定；资源权重和凭据另装/另配 |
