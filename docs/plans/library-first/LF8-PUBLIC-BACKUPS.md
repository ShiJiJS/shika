# LF8：开放完整备份入口与旧版兼容

[Draft PR #90](https://github.com/ShiJiJS/shika/pull/90)基于[系统文件往返PR #88](https://github.com/ShiJiJS/shika/pull/88)，推进#24／#33／#32。当前入口此前只有测试服务额外追加backup_v2，正式服务即使有完整实现也不会显示；本段让公开info如实声明能力，删除测试追加分支，让原生流程经同一个公开合同进入。

开放依据：完整管理图与v1转换、来源校验及不复活永久删除内容已有服务检查；原生文件、传输、安全日志、明确确认、恢复前快照／历史及强停有PR #53／#54；页面原型有#71；#88补实际系统文件＋HTTP同次往返、小文件／约41 MB文件及取消。上述阶段是明确范围依据，不代替本段源码回归或目标手机验收。

变化只涉及公开能力声明、测试专用注入移除、合同检查与说明。默认32 MiB不变，64 MiB大文件测试继续隔离；App已有旧服务回退页面和v1原任务协议保持，不迁移或自动重放未完成命令。冻结原型独立不改，当前正式8760、NAS、SDK、签名及部署不改。

本段检查：公开info具备完整版本／上限／代次／历史合同；客户端拒绝不完整声明，旧服务与只有上限而未声明能力保留旧入口；现有v1与故障测试仍通过。运行服务与客户端完整回归，记录真实失败和范围；再以删除注入后的实际服务跑一次系统文件保存／取消／重新选入／完整恢复，记录公开info前后，不借用旧24点冒充新结果。

当前尚未发布APK或关闭整项。目标手机／NAS、云文档提供器、原签名覆盖升级及发布回退继续等待对应验收；可独立完成的检查先推进。
