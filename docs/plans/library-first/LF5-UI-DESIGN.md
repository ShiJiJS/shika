# LF5 阅读界面的实现约束

北极星：从已挑选的图包直接连续阅读，重开继续原页，返回仍在原来的媒体库或标签结果。以整包管理；图片没有单张标签/删除入口。

已确认的是独立 `design/reference/library-first/` 原型，图包卡片进入专用阅读页面。沿用 Paper 的墨绿/橄榄/纸白、PaperSerif 标题和原生控件，不重新探索风格。冻结 tag `design-lf-2026-10-23` 不改动。

普通字号顶栏52dp，主标题20dp、副信息12dp；图库与视频既有P2比例保留。阅读内容占剩余空间，完整图片适配，纵向按真实宽高占位。工具图标21dp、标签12dp，页码/范围均12dp；搜索、整包标签和管理面板仍复用既有Paper组件。系统状态栏/底部安全区来自Android，不额外画HTML home indicator。顶栏最小52dp，标题和副信息按实际字体自然撑高，不估算固定大字号行高；大字体允许工具文字增加高度/换行，四字工具按两字一行且图标上对齐。

底部为页码滑条、总览/阅读方式/整包标签/沉浸、来源范围与下一包。普通阅读的上一包在更多/本次范围中可达；快速整理专属工具属于LF6。横向跟手翻页、左右方向、双击缩放、宽度适配可纵向滚动；纵向连续拼接、间距可配置，滚到底只显示末尾动作，不自动换包。总览和范围按页读取，未知或失效项说明原因。

成功阅读不增加确认问题。页码、模式、方向、间距和适配随包保存；首次默认仅作用未设置包。图片实际显示后才记录打开和最近，单页失败可重试或跳过，503/429只有限重试。保存失败保留当前位置和原操作，先查询回执，未知结果明确要求用户再提交原请求；离页时可留在阅读器处理或返回已确认位置。系统返回先收起缩放/沉浸工具或面板，再回来源。

初始清单和静态工具栏就绪后恢复纵向位置，避免临时窗口把页内比例提前压缩；工具在已打开后以140ms收展，降低动态时不创建零时长尺寸动画。沿用原生页面进入、跟手PageView、Paper底部面板和Ink反馈，不增加装饰动画。

计数口径：从图包列表已选定目标开始，点击与页面切换分开，滑动另记。旧详情入口只有封面/标签，不能产出实际阅读与续读；冻结原型是1次卡片点击、1次页面切换进入阅读，0次额外决定，返回1次且保留列表。当前实现按同一路径，首次Android全流程已走通，读取/保存成功后无额外确认；错误处理仅在真实失败后出现。

原生主路径覆盖390×844普通字号及360×740双倍字号的公开花卉素材；图像本身与原型合成SVG不同，看布局/比例/颜色/交互，不要求素材像素一致。844×390横屏由真实资源widget路径检查，不能冒充原生横屏截图；暗色、完整动作和大图性能仍需后续验收。LF5尚未完成，最近图包列表界面和全局默认设置接线另有剩余工作。
