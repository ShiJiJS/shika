# LF8：图包库继续阅读

本段属于已确认原型的功能补齐，沿用 Paper 视觉与媒体库优先结构。目标：图包库提供真实最近打开图包的续读入口，点入后仍在当前完整媒体库范围阅读，返回保留原来的位置。冻结参考 `design/reference/library-first/` 不修改，生产 App 不导入参考源码或素材。

## 数据与范围约定

- 只在图包媒体库、无目录/标签/阅读状态/搜索条件且非多选时显示。标签结果、最近页和筛选结果继续由各自范围进入阅读器。
- 使用现有只读 `GET /api/v1/packs?source=recent&sort=recent&read_state=all&offset=0&limit=1`；不从当前24条分页缓存寻找，不以进度更新时间冒充打开顺序。
- 最近记录由服务端实际打开事件决定。只考虑启用、在线根目录中的可读图包；回收、缺失和无可读页时使用下一条实际打开记录，不把从未打开的包补成续读。最新已完成图包仍可再读，与原型一致。
- 封面与摘要读取均不创建阅读会话、不写最近、不更新进度。没有实际打开记录时隐藏续读区；没有可信页码时显示位置待确认，不猜成第一页。
- 点击续读将该包作为锚点，传递当前媒体库的来源、排序和完整查询。使用已有阅读器与实际解码后的打开/进度协议；不能把 `recent/limit=1` 当成阅读范围。
- 返回媒体库重新读取真实进度。位于顶部时保留顶部；深处原有锚点和行内偏移随续读区出现/隐藏调整，不多跳一行。退出多选重新核对摘要。

## 模块职责与异步边界

`LibraryRepository.loadPackContinuation()` 是可选只读摘要接口；旧适配器默认无摘要。真实服务适配器复用图包解析与权限/连接代次检查，拥有独立取消通道。摘要与普通列表读取互不取消，切换连接和销毁仍由连接所有者取消。

页面只决定展示资格、加载状态、当前位置和显式点击。摘要与首屏列表同时读取，结果就绪后发布，避免首屏完成后突然插入续读区。翻页不重新读摘要；旧搜索或旧连接的晚到结果不能覆盖新范围。服务不支持图包阅读会话时不请求摘要。

摘要失败保留原图包列表，提供就地重试；失败不能进入一个宽泛或虚构的阅读范围。列表加载、备份恢复或已有动作未结束时禁用续读点击。

## 布局与状态

普通目标窗口对齐参考：两侧16dp，封面44×58，横向间距11，标题16、说明12，标题前后各3，进度线2dp占满文字列。原型85dp是最小高度；Android实际字体可能具有更高的回退字体行高，使用与真实文字一致的 TextPainter 测量后自然增高。系统字号保留，不靠裁切或缩字凑高度。

错误说明最多两行，保留重试动作可达；很长的服务错误允许省略。成功标题与页码最多一行。进度线只使用实际页码/总页数。沿用已有路由过渡、加载反馈和减少动态效果设置，本段不另造动效。

共享“更多”菜单打开时收起当前搜索键盘，再选择多选/整理等非文字动作。短横屏实测发现，保留键盘会使固定搜索区与底部批选区超过可用高度；该修正同时适用于视频与图包，查询本身不清空。

本段不解析作者、不重排当前页、不用筛选数量代替两类全库计数。标题/作者、权威分类总数、服务端一致排序，以及完整阅读/管理页的最终视觉和性能仍按 LF8 台账推进。

## 验证约定

服务端针对实际打开历史、27包超过单页、进度与打开顺序不同、旧会话拒写、回收/缺失/无可读页、根目录停用/离线和只读快照检查。客户端验证摘要与分页互不取消、连接切换丢弃旧结果、失败重试、未知页码和多选前后深列表位置。

原生检查使用已有 emulator-5554、完整 App 与真实服务适配器，新建8768隔离服务与DB，公开2视频/4包/24PNG；预置页码但不伪造最近打开。实际从卡片打开、翻一页、返回，续读后核对完整4包范围，再检查搜索/多选隐藏、长错误重试和最近页隔离。每次保留请求、进度前后值、源码SHA、窗口/安全区、ADB截图与26个源文件SHA；结束恢复设备配置并仅移除本次容器。正式8760与NAS不参与。

固定源码c4aaf3b，普通三轮/大字/短横屏共50个原生检查点、客户端471项及服务端16项通过。两轮独立视觉复核与202份输入校验见[证据目录](https://github.com/ShiJiJS/shika/blob/c9c6363ab1ca3bb7d72c96499432a289de33f187/docs/plans/library-first/evidence/lf8-pack-continuation/README.md)，已提交[Draft PR #59](https://github.com/ShiJiJS/shika/pull/59)；LF8/#33与总任务#24保持开放。
