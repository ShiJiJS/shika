# 图包切换、回收反馈和批量整理

2026-11-02，按用户本轮连续反馈统一处理，对应 [#179](https://github.com/ShiJiJS/video_viewer/issues/179)、[#180](https://github.com/ShiJiJS/video_viewer/issues/180)、[#181](https://github.com/ShiJiJS/video_viewer/issues/181)、[#182](https://github.com/ShiJiJS/video_viewer/issues/182)。只推进这组问题，其他持续开发及验收仍暂停。

## 行为

- 前后切换：后台预读、查找邻项和范围列表改用独立读取；切换范围、退出或换连接时仍能统一取消。后台预读合并重复请求，连续点击只启动一次前后切换。旧读取返回时核对原图包，不能误切换、误结束或污染新位置。
- 回收反馈：悬浮按钮从40dp扩大到80dp；去掉“正在移入回收站”。本地记录移除后继续浏览，服务确认完成时在顶部显示两秒“已移入回收站 / 撤销”，沉浸时也可操作。自动进入下一个图包保留这次提示，之后主动切换即清除。顶部提示避开返回和更多按钮，也不遮底部导航。结果未知不显示成功，原操作保留在移除记录中查询。最后一个图包留在末尾页，可撤销或返回来源。
- 数量与位置：本地接纳移除后立即扣除显示数量，并按移除项的原始序号重算显示位置；确认回执不重复扣减，撤销或明确失败时恢复。服务端固定范围和原始序号不重建，避免删除后排序漂移、跳过内容。
- 媒体库多选：搜索旁有“多选 / 完成”，也可长按封面选择。选择期间保留封面点击勾选，支持跨分页选择和全选匹配项；底部显示数量并可批量移入回收站。确认说明选中数量，取消不写入；只提交选中ID，成功项清除选择，未确认结果只查询原请求。每次最多1000项，保留源文件，仍可在回收站恢复。退出选择恢复搜索与排序，批量删除为空后也能退出选择。

## 根因和验证

原客户端在每次读取图包队列前调用同一个cancelQueue，导致后台预读和用户导航互相取消；导航等待阶段也未防止重复点击。新增真实本机HTTP延迟响应复现，修复前两项失败：独立队列读取被取消，前项查找返回空。修复保留显式取消和连接隔离，未自动重放未知写操作。

集中验证覆盖真实HTTP并发/取消/过期返回、重复点击、异步回收及数量恢复、顶部撤销、最后一项、横竖屏与大字体、多选取消、跨页批量回收及丢失回执后查询。Flutter analyze无问题，图包相关308项测试通过。正常/同号回退包均完成构建、原签名、包名、版本及资产核验，NAS回读摘要一致。没有重跑整个客户端851项旧版结果，也未进行实体手机试用，不合并累计计数。详见[第31版交付记录](../../nas-app-preview-2026-11-02-code31.md)。

版本：`0.2.0-preview.25+31`。沿用原Windows签名，服务端preview.8和独立原型不改，无数据库迁移，不对真实收藏做删除试验。
