## 操作与兼容

快速移除使用已有的逻辑回收 API，不携带能推进阅读位置的原图包快照。固定阅读范围及页码保存继续使用现有阅读接口，避免后台回收回执修改较新的位置。移除前保存当前阅读位置，等待的是阅读位置保存和本地操作记录写入，不等待回收请求完成。

请求结果未知时保留原始请求号，只查询原结果，不自动重复发送。退出阅读器后后台请求仍可完成，操作记录绑定原服务连接；服务切换或管理数据恢复后不会向新资料库继续写入。恢复使用现有撤销接口，普通阅读的确认移除流程保持。

本次仅修改 Android 客户端；NAS 服务沿用 preview.8，无数据库迁移。安装包版本为 `0.2.0-preview.23+29`，沿用原签名，支持覆盖第 28 版。

## 验证

- 集中针对性客户端测试：71 项通过。涵盖慢响应、断连、两次自动重试、最终失败、缩略图排队/取消、阅读方式切换、未知结果查询、迟到回执、超过缓存窗口的连续移除、横竖屏及大字体。
- Flutter analyze：无问题。
- Linux 隔离容器中运行逻辑回收、图包操作和阅读接口测试：35 项通过；一条现有 Starlette/httpx 弃用警告。
- 完整客户端测试及安装包检查结果在本次提交完成前补充。

本机 macOS 不提供现有服务文件执行器依赖的 `renameat2`，因此服务测试使用 Linux 容器；本次未操作 NAS 服务、实际资源或数据库。
