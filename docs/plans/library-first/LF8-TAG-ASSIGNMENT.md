# LF8 视频与图包的标签分配

按已确认的 Paper 原型继续实现标签分配，从 #73 的标签目录进入单项／批量编辑。原型仍在 design/reference/library-first 独立保留，不引入运行时依赖，树 1cbf605 不改。

用户在媒体库、预览或图包详情中编辑当前内容，或者在媒体库跨页选择后追加标签。视频和图包分别读取、创建、关联各自的标签；同名允许共存。单项保存替换整项标签；即使批量选择只剩一个目标也只追加，保留原有标签。旧视频入口的批量移除能力保留。

标签分配共用 MediaTagEditor 状态机与 PaperField／SheetFrame，公开 TagEditor、PackTagEditor 保留既有返回类型。共用的是分页、草稿与布局，不合并命名空间。目标 ID 在打开时复制固定。视频名称来自服务已完整同步的定义缓存；图包保留独立按 ID 核对、缺失提示及响应版本排序，迟到的名称不会覆盖更新的查询结果。未知单个视频不会以空选择覆盖标签。

沿用 21dp 面板标题、13dp 范围说明、20dp 横向留白、现有色板、标签控件及 240ms 路由。取消／保存使用明确文案，操作区固定在可滚动内容之外；横屏键盘极短时沿用 SheetFrame 的滚动动作区。新增名称使用持久外置字段标签。搜索作为真实长目录的兼容补充，与新增字段分开，搜索词不会误建标签。新增名称可显式“添加”，或随保存先创建再关联；显式添加的定义已保存，后续取消仅取消本次关联草稿。

选择跨搜索／分页保留；读取失败保留列表和偏移并重试，写入错误保留草稿且不被搜索清掉。保存失败保留已创建定义的 ID，重试关联不重复创建。正在提交时禁止重复写、返回、关闭及拖动／遮罩退出。连接改变或恢复未确认时拒绝旧回调继续提交。256个标签与100字名称遵守已有协议。
