# LF4 媒体库与四入口的设计记录

意图：在现有 App 中按用户确认的完整原型改流程、加图包功能，视觉沿用 Paper 与冻结的 P2 规范；不是重新探索方向。当前处于原生四入口接线与真实服务验证阶段。

北极星：媒体库确定范围，视频预览和图包阅读从内容或标签结果进入，返回各自来源。

## 导航与来源

主导航固定为媒体库、标签、最近、设置。媒体库、标签、最近分别记忆视频/图包类型，每个来源的每种类型拥有独立查询、排序、批选和滚动容器。标签先选择交集条件，读取服务端匹配总数，再进入结果；视频还可直接预览这个交集，返回落到该来源的结果页。底部明确显示已选标签数和匹配总数，结果的搜索与目录不会改写媒体库草稿。

视频预览继续使用 LF3 的独立 route 和固定范围。返回由来源页的稳定 ID、邻居及行内偏移恢复；管理页面覆盖在保留的主工作区上，回设置时不会销毁媒体库查询。旧服务继续使用兼容入口。

新冷启动的媒体库只恢复媒体库来源的上次范围；来自标签的保存范围留在标签来源中，最近直接读取实际打开记录。这取代 LF3 临时用最后一个来源填入媒体库的做法，避免来源混合。保存的预览元数据不自动播放。

## 比例与组件

普通字号使用 P2 的 52dp 顶栏、40dp 类型栏、49dp 导航内容；侧距16、列距12、行距18，390宽封面211dp、360宽185dp。系统安全区由 Android 提供，不画原型中的假 home indicator。

卡片标题16/1.5、次要信息12、标签12/1.6，元信息后留4dp；作者/方向亮色#626E59、暗色#9AA494。视频封面保持横竖原比例，背景深墨绿，中央播放标识表明进入预览。搜索16，搜索区55dp、范围工具60dp；原生菜单、标签编辑与设置继续复用 Paper 组件。LF8按最终渲染基线复核这些共享尺寸，导航按钮在300dp内居中，不绘制额外选中短横线。

大字体保持系统文字缩放，增加标题、类型栏、卡片文字区和导航高度，计数与操作拆成两行；不缩小文字来维持固定高度。普通字号的尺寸不随这个适配改变。

图包媒体库在无筛选/搜索且非多选时显示真实最近打开包的继续阅读条，摘要独立于当前分页缓存；点击锚定该包，但仍使用原媒体库完整范围。摘要和封面只读，未知页码不猜测；失败保留列表并就地重试。普通最小85dp，封面44×58、文字16/12、间距11，实际字体行高超过估算时自然增高；长标题/说明允许省略，主动作可达。标签结果、最近页与多选不显示全库续读条。打开“更多”菜单先退出搜索焦点，避免短横屏键盘与批选操作区互相挤占。

## 异步和阶段边界

类型切换先取消旧来源读取，再在帧后启动新来源读取，避免旧页的取消误伤新页。目录失败不扩大为全部目录；总数来自真实接口，不用已加载条数代替。分页失败保留已有卡片和原偏移重试；失败和重试入口固定在列表上方，深列表无需回顶。图包刷新失败按刷新重试，追加失败按原偏移继续，避免重试误追加。封面繁忙只自动重试两次，之后保留手动重试；401 仍结束连接，不循环重试。

批选使用独立ID快照，完整范围先在服务端一次读取，再允许单项排除；取消或失败保留旧选择。查询、来源、连接及手动选择会使迟到全选失效。标签分页错误固定在列表上方；普通翻页失败按原偏移重试，列表成员变化则从头刷新。批量追加即使只剩一项也不替换旧标签。五万项以上明确要求缩小范围，不能静默截断。

图包卡片标签与视频采用相同的12dp/1.6单行名称显示，摘要自带本包独立名称。编辑/筛选中的原选择按ID直接解析，不依赖首50项。读取失败保留草稿，名称未确认或标签已移除时先解决再保存；较早响应不能覆盖新名称。长中文名称在选中项内最多两行，保持可读与删除按钮位置。成功编辑会更新仍打开的详情，重新进入编辑不恢复旧选择。

图包列表返回也保存稳定ID、交错前后邻居、全局索引与行内偏移。沿用视频定位模式，按原完整查询在服务端定位，不保留无限卡片或静默回全库；窗口最多120项，前补/丢页补偿像素。当前项退出交集时就近恢复，所有候选消失时收敛到有效位置。失败或当前代次意外取消保留旧列表与待定位目标，固定入口按原读取意图重试；改查询或连接使旧结果失效。大字号按实际列表头计算前补阈值。

图包卡片目前进入真实详情，整包标签可编辑；横翻/纵向拼接、进度和图包最近由 LF5 接入，快速回收与撤销由 LF6 接入。设置继续保留现有服务连接、目录、回收站、备份恢复与操作状态，完整 v2 数据与偏好迁移仍属于 LF7。

## 取证

实际 Android 模拟器连接 8761 隔离 FastAPI 服务；测试图包来自公开花卉素材，共27包81页，用于跨24条分页验证。不会使用真实 NAS 文件制造故障。截图来自 ADB，记录实际视口与系统安全区；网页 HTML lint 不适用于原生界面。

独立视觉评审以冻结原型和这些已确认尺寸为标准，不重新评分或更换方向。完整跨设备、性能及原型逐项验收仍由 LF8 收口。


## LF8 分类总数补齐（910cfb2 / PR #60）

媒体库类型栏使用同一份服务端完整可浏览目录快照的两类总数，15dp类型名、12dp数量、间距7dp；标签/最近隐藏全库标记。失败为“—”，旧服务不显示；大字长数横向滚动而不缩字。请求独立、操作完成后只读重取，约定和证据见[分类总数](LF8-CATALOG-COUNTS.md)。横屏键盘过渡时标签操作区最多使用实际可用高度60%，超出可滚动；普通高度保持自然底部布局。


## LF8 图包呈现与排序（4e391a2 / PR #61）

主行使用可识别标题，次行有作者时显示作者，否则保留可读数；不改原名/路径/ID。左上阅读角标显示实际页码，未知不猜，多选隐藏；右下仍是总页数。阅读标题和作者/编号、详情原目录与完整范围语义见[呈现约定](LF8-PACK-PRESENTATION.md)。图包名称排序由服务端对完整结果做中文标题排序，列表/锚点/全选/阅读范围一致。大字长工具行可横向滚动，保持字号与完整动作。

媒体库/标签结果的两类网格：安全区后的内容区域横向且高不超过500dp时四列，其余两列，不以键盘高度判断。卡片自然行高使用本机字形、相同样式和系统字号实测；渲染、分页与返回复用最后布局几何。旋转/字号变化保留稳定ID与行内偏移，整行可以包含相邻成员，不重排或重查服务结果；最近图包保留一列，最近两类均使用共享一列历史行，详见下节。见[卡片与重排约定](LF8-CARD-LAYOUT.md)，其余实际差异仍见RESULTS。

具有video_name_order能力时，视频名称排序统一传sort=name和name_locale=zh-CN，完整列表、锚点、全选和播放范围共享同一服务端键；旧服务保持旧请求。固定范围公共sort仍为name，不让旧App解析到新枚举；内部原序和成员保持。预览退出先卸载原生画面、等本帧结束再释放播放器和返回，避免退场重建已销毁的原生视图。约定见[视频中文顺序与退出](LF8-VIDEO-NAME-ORDER.md)。

## LF8 最近记录完整形态

最近视频与图包复用一列历史行和分类说明；标题18、说明13、封面64×78、侧距20、图文间距16、普通行111dp，具体见[最近记录约定](LF8-RECENT-HISTORY.md)。最近不再出现媒体库搜索和范围工具栏；行点击进入该来源固定范围。视频显示标题隐藏已知扩展名、时长向下取整；原名/路径/ID和中文排序依据保留。空状态按原型使用48dp上下留白的简洁文字。右侧真实总数为既有原生功能兼容差异。

两类最近共用实际字体测量几何，字号/旋转保留锚点和行内偏移。视频同样执行24项分页、120项窗口及前补/淘汰补偿，页尾定位先补足可见尾部。底部导航标签保持单行，极端字号省略显示仍保留完整语义，避免换行挤出导航高度。新规则来自冻结原型与实际布局测量；未改变用户确认的结构与视觉方向。

短横屏键盘占据大部分空间时，底部导航暂时隐藏；可用高度不足标题、分类与搜索操作时收起页面标题栏，分类和搜索保持可用。键盘关闭后恢复，来源和查询不变。保留列表的失败提示统一最近20dp/其它16dp侧距、12dp错误色和原重试意图；实际高度预算包括搜索摘要与工具行；双倍字号不足时也临时收起标题，保留整个动作。修后99个同源原生点与三轮独立问题复核见[最终证据](evidence/lf8-recent-history-final/README.md)，完整其它页面和动作继续。
