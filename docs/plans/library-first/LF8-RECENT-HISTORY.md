# LF8 最近记录完整形态

本轮继续迁移用户已确认的完整原型，不探索新方向。北极星仍是：在媒体库确定范围，从对应来源进入视频预览或图包阅读，返回原来源。参考目录独立冻结，后续可删除；本轮不修改参考文件。

## 形态与显示

最近的两类内容都使用一列历史行；媒体库和标签结果保留现有网格。最近页没有媒体库搜索、排序或范围工具栏。普通字号：侧距20dp，封面64×78dp、图文间距16dp、标题18dp、说明13dp，说明距标题8dp，上下各16dp与1dp分割线，行高111dp。视频说明为时长，图包说明为实际保存图片的位置；未知页码不猜。标题、说明保持一行省略，箭头始终可见。实际系统行高超过封面时，按窗口中真实标题和说明测量统一行高；列表头也随系统字号增高；字号或旋转改变后仍保留条目和行内偏移。

列表头复用13dp分类说明和真实总数。原型没有右侧总数，原生图包已有真实包数，本轮保留并统一到视频，标为已存在功能的兼容差异。最近没有新增批选菜单；共享历史行正确呈现已有选择状态，点击在选择状态下切换该项，不打开播放器/阅读器。

视频的媒体库卡片、历史行及预览范围标题隐藏已知视频扩展名，原文件名、详情/删除中的文件名、路径、ID和服务端排序依据保留。只去除最后一个已知后缀，未知后缀和仅有扩展名的隐藏文件不改。列表时长按播放器的整秒时钟向下取整，如5.98秒显示0:05。此处只改变客户端显示，不改服务端媒体信息。

## 来源、范围与恢复

最近视频与最近图包分别读取实际打开记录，按最近时间排序，不继承媒体库搜索、目录或标签。浏览、封面和只读重试不会新增打开记录或写进度。行点击仍进入真实预览/阅读器；固定范围包含对应来源完整结果，不扩大到全库，也不限定到加载的第一页。返回保持来源、稳定ID、邻居和行内偏移，媒体库草稿独立。

视频分页落实24项一页、最多120项窗口。向前补页或向后淘汰都补偿像素；成员/总数/偏移变化使旧分页不再相邻时，保留旧列表并要求按原范围重新定位。定位目标落在24项页尾时，先读取足够后续条目再恢复像素，避免短列表最大滚动距离把位置夹错。当前代次的意外取消有明确重试入口；迟到请求仍失效。

## 验证边界

组件测试覆盖180条历史中的跨页与窗口淘汰、页尾锚点重排、字号变化、选择状态、清空历史及独立媒体库搜索。真实AVD流程使用隔离8768、2个公开视频与4个公开图包，验证真实首帧、最近固定范围、返回、故障保留和只读重试。不会用NAS或生产8760制造故障。修后结果见[固定点证据](evidence/lf8-recent-history-final/README.md)：99个同源原生点、518项客户端及26项相关服务检查通过。LF8整体验收仍按RESULTS开放项推进。

## 短横屏键盘与错误提示

实际844×390键盘状态曾将内容区域压到22dp，搜索区需要55dp。键盘出现时隐藏底部导航；剩余高度不足标题栏、分类、搜索与操作空间时，暂时收起页面标题栏，分类和搜索保留，关闭键盘恢复。完整高度预算包含搜索摘要与工具行，不能用48dp占位低估双倍字号动作。两类组件检查覆盖短横屏280dp键盘与360×740双倍字号303dp键盘，验证查询不丢失与导航恢复。两类已有列表读取失败统一使用内容侧距（最近20dp、其它16dp）、12dp错误色与原重试动作。

独立存量评审共三轮，同一问题清单的错误提示边距/颜色及大字真实键盘动作裁切均已按修后截图关闭。修正大字键盘的新增两项检查在旧实现均失败，修后完整客户端518项通过；原生等待实际IME非零，并验证整个操作按钮在键盘顶以上。

短横屏原生测试曾遇window/settings系统服务退出。之后按现有开发文档受控重启同一AVD、切换host后端，保留userdata，无wipe、卸载或清数据；确认服务与显示基线恢复后，完成普通三轮、大字、短横屏五轮17点及14点相邻回归，共99点。源码固定b2ce2a8（生产界面树01bf735），323份输入只读复核通过，恢复日志单列，不能由Binder错误推断磁盘/GPU根因。

短横屏最近视频保留先前稳定ID时，实际scrollOffset=98、列表头52、步长111，新增条目位于先前条目前，首行上部在视口外是正常位置恢复，不强制回顶。原型/原生同状态顶部400dp等比对照与完整原图均留存；右侧真实总数仍属已说明的兼容差异。

早期2e971ac的15点与101份输入原样保存在阶段目录；最新证据单独放在[lf8-recent-history-final](evidence/lf8-recent-history-final/README.md)。当前仅补最近/来源返回和键盘/错误组合，完整预览、阅读、管理、动作录屏、性能与目标设备仍待验证；未关闭REC/UI整项。
