# LF8 最近记录完整形态

本轮继续迁移用户已确认的完整原型，不探索新方向。北极星仍是：在媒体库确定范围，从对应来源进入视频预览或图包阅读，返回原来源。参考目录独立冻结，后续可删除；本轮不修改参考文件。

## 形态与显示

最近的两类内容都使用一列历史行；媒体库和标签结果保留现有网格。最近页没有媒体库搜索、排序或范围工具栏。普通字号：侧距20dp，封面64×78dp、图文间距16dp、标题18dp、说明13dp，说明距标题8dp，上下各16dp与1dp分割线，行高111dp。视频说明为时长，图包说明为实际保存图片的位置；未知页码不猜。标题、说明保持一行省略，箭头始终可见。实际系统行高超过封面时，按窗口中真实标题和说明测量统一行高；列表头也随系统字号增高；字号或旋转改变后仍保留条目和行内偏移。

列表头复用13dp分类说明和真实总数。原型没有右侧总数，原生图包已有真实包数，本轮保留并统一到视频，标为已存在功能的兼容差异。最近没有新增批选菜单；共享历史行正确呈现已有选择状态，点击在选择状态下切换该项，不打开播放器/阅读器。

视频的媒体库卡片、历史行及预览范围标题隐藏已知视频扩展名，原文件名、详情/删除中的文件名、路径、ID和服务端排序依据保留。只去除最后一个已知后缀，未知后缀和仅有扩展名的隐藏文件不改。列表时长按播放器的整秒时钟向下取整，如5.98秒显示0:05。此处只改变客户端显示，不改服务端媒体信息。

## 来源、范围与恢复

最近视频与最近图包分别读取实际打开记录，按最近时间排序，不继承媒体库搜索、目录或标签。浏览、封面和只读重试不会新增打开记录或写进度。行点击仍进入真实预览/阅读器；固定范围包含对应来源完整结果，不扩大到全库，也不限定到加载的第一页。返回保持来源、稳定ID、邻居和行内偏移，媒体库草稿独立。

视频分页落实24项一页、最多120项窗口。向前补页或向后淘汰都补偿像素；成员/总数/偏移变化使旧分页不再相邻时，保留旧列表并要求按原范围重新定位。定位目标落在24项页尾时，先读取足够后续条目再恢复像素，避免短列表最大滚动距离把位置夹错。当前代次的意外取消有明确重试入口；迟到请求仍失效。

## 验证边界

组件测试覆盖180条历史中的跨页与窗口淘汰、页尾锚点重排、字号变化、选择状态、清空历史及独立媒体库搜索。真实AVD流程使用隔离8768、2个公开视频与4个公开图包，验证真实首帧、最近固定范围、返回、故障保留和只读重试。不会用NAS或生产8760制造故障。实际结果、截图、源码固定点和独立评审记录在本轮证据目录补齐；在完成前不宣称LF8整体验收通过。
