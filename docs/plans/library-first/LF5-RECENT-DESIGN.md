# LF5 最近图包接线约束

任务：从实际阅读历史找到整包，继续上次图片；返回仍是最近来源，媒体库自身搜索与筛选保持独立。管理单位始终是包。沿用独立冻结原型 `design/reference/library-first/app.html` 的 recent 状态，不改参考目录。

视觉：Paper墨绿/橄榄/纸白和PaperSerif标题，52dp普通顶栏与类型栏复用现有壳。最近页为纵向历史条目，页面侧距20dp；64×78封面、16dp图文间距、18dp包名、13dp阅读位置，条目上下各16dp与底分割线。普通条目111dp，大字号允许增加高度；文本截断但不挤掉进入箭头。顶部13dp“最近阅读的图包”，右侧真实包数。无记录使用空状态；加载和失败/重试复用既有列表组件。

来源：最近不沿用媒体库目录、搜索、标签与阅读状态；默认按最近阅读时间倒序。查询模型自身携带来源与排序，列表/下一页/全选/稳定定位/阅读入口使用同一对象。最近阅读入口不扩大为全库，也不只取已加载24项。为兼容旧服务，缺少阅读能力时在发出列表或全选请求前明确提示升级，不回退全库。

阅读位置：服务端按当前清单中稳定pageId的实际位置返回零基page_index；文件名、旧ordinal或客户端已加载项数均不能代替它。客户端显示“第n / 总数张”；旧服务缺字段或保存页已不在有效清单时不猜页码。读取摘要不修改进度或最近。

进入/返回：一行点击进入同一真实阅读器，实际当前首帧才更新最近；封面、缩略图与预加载不更新。当前已读包可因新打开移到历史顶部，但本次阅读成员仍固定。离页保存后按原视口包ID/邻居与行内偏移重新定位，合法边界处允许夹到顶部；不把历史重排误当成回到全库。最近页使用单列定位，媒体库继续两列定位。

验收：真实Android/8761中以73包、27条明确标记的历史夹具加1个本次实际打开包形成28条最近，检查分页尾项、完整选择、固定28包阅读范围、重开上次页与返回重排定位；45个未读反例不进入范围。历史夹具不冒充本轮实际显示过27包。普通/双倍字号和横屏资源widget检查分开记录，实际截图与性能另行验收。
