# LF8 内容页强停与显式恢复

基于草稿 PR #85，完成当前阶段后按用户要求暂停。仅验证普通视频、横向全屏、纵向图包三种内容页，各一次真实双进程运行；不启动下一阶段，不将单次结果称为三轮稳定性验证。

每例七个检查点：初始媒体库、内容打开、冷启动媒体库、最近、只读边界、用户明确重开、返回来源。宿主在内容实际播放／图片解码且进度已保存后执行 Android force-stop，记录旧 PID 消失和新 PID；冷启动先落媒体库，确认没有自动打开视频或阅读器。独立夹具的七张管理表在强停后与只读边界一致，只读阶段无写请求、视频流或阅读原图请求，之后才允许点击重开。

视频核对固定范围、当前视频、最近记录及明确点击后真实播放。现有协议不保存视频秒数，本阶段不声称按秒续播。图包核对保存页码、纵向偏移、阅读模式和相对画布几何；重开新范围是合法写入，不与冷启动只读混淆。

入口复用生产窗口配置、生产 App 和 Repository，以专用安全凭据键和偏好文件隔离数据；不是正式 main 默认凭据、签名升级或发布 APK 的验收。生产改动仅抽取原有窗口初始化函数，值与执行顺序不变。使用专用 AVD、8768 可丢弃公开夹具；不改 NAS、正式 8760、SDK、原签名或独立原型目录。

当前已完成代码和驱动准备，组件 18 项与静态检查通过；原生与证据结果待本阶段实际运行后补充。仍不宣称 LF8 或整个产品完成。
