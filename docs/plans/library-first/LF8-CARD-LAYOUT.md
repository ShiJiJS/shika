# LF8 共享卡片密度与短横屏网格

继续按已确认的library-first参考实现，不修改独立原型。媒体库及标签结果的两类网格共用12dp、1.6行高的标签样式，元信息行与标签间距4dp；标题16dp/1.5、封面与标题8dp、元信息最小28dp、列距12dp、行距18dp保持。普通宽度封面211dp，380dp及以下185dp。

卡片行高使用实际文字样式、系统缩放、方向与本地字体的中英文字形测量合并计算，移除固定79dp文字区估算。渲染网格、滚动索引换算和返回定位复用同一份最后布局几何，避免显示行高与定位步长分叉。原生回退字体可能使自然行高比CSS多约1dp，不裁字或缩字号迁就截图。

## 列数与重排

排除系统安全区后的内容区域为横屏且高度不超过500dp时采用四列，对齐冻结CSS；其它媒体库/标签结果保持两列。列数不依赖键盘占用高度，打开键盘不能把竖屏变为横屏网格。最近图包继续是一列；最近视频的完整形态仍在REC-01/UI-02中待核对，本段保留其现有两列。

布局前保留实际可见成员ID、行内偏移和查询代次；旋转、封面高度断点或字号导致列数/行高变化后，在新几何中恢复包含该ID的行。四列可能在锚点前显示同一行的相邻成员，不能为强行把锚点放在第一列而重排服务结果；再转回两列以新的首个可见行续接，漂移不超过相邻行。原位置在顶端时仍为顶端。查询变化、已有异步定位或阅读路由持有返回位置时，原流程优先；几何重排不重查目录、不创建播放/阅读范围、不改变筛选/排序/选择。

渲染布局缓存保留旧的实际头部高度与步长，不能用新字号倒算旧像素对应的成员。前补、追加丢页、返回锚点和可见范围计算均使用当前实际列数，视频移除原来硬编码的两列换算。分页仍为24项、窗口上限120项，服务协议和ID不变。

## 验证与边界

组件覆盖视频/图包的标签12dp/1.6、4dp上距与8dp标题间距，120项样本中的两列/四列/两列切换、非四倍数锚点附近可见性、字号变化保持行内偏移、重排不新增查询，以及键盘高度不影响列数。原生用真实服务和公开2视频/4包/24PNG核对两种网格与滚动后的标签，搜索一包再清除保持完整成员与全库计数，进度/最近只读。

标准参考视口与原生实际安全区分别记录，不挪列或拉伸截图。桌面原型滚动条占位造成的列宽差、标签顺序、次要文字颜色、菜单图标、视频中文排序、最近形态和其它完整页面/动作仍按RESULTS处理；本段不据此关闭UI或LF8整项。无服务端生产代码修改，不以本段客户端检查替代原服务端或目标设备性能证明。
