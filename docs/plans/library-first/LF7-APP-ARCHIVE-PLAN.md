# LF7 下一步：App 管理文件流程

依赖 Draft PR #52 的恢复协调器。本文是继续实施的边界，不是已完成或已通过原生验收的声明。沿用冻结的 `design/reference/library-first` 页面与尺寸，设置中的导入、预览、根映射、完整替换确认、任务与历史入口不改产品结构。

## 当前需要替换的接线

`ui/home.dart` 的 `BackupFiles` 仍收发完整 String；`NativeBackupFiles` 用 `readAsBytes` / UTF-8 解码，保存也构造整份 Uint8List，固定32MiB。`library/server_backups.dart` 与 `server_api.dart` 同样把 HTTP 响应聚成 BytesBuilder，再取完整文件。这些路径适合既有兼容v1，不能用“调大限制”作为v2文件接入。

`BackupPreview` 仍以 LibrarySnapshot 和全部根为中心。新流程需要独立的已校验预览元数据及分页根描述，不在手机解码整个备份图。原服务器 v1 工作日志与未知回执继续按原协议查询，不能升级到新前缀后重发旧请求。

## 文件与传输接口

新增文件句柄描述，包含本机私有文件、字节数、SHA及所属服务/原代次；工作日志只保存标量和句柄，避免将文件塞进安全存储。读取与写入按块进行，并提供取消、关闭和确定的清理归属。应用退出或缓存被系统回收时，保留原任务身份；允许再次 GET 同一导出文件，不能为找回文件自动新建导出任务。

系统文件选择先复制到应用私有暂存并计算摘要；完成后才写原请求日志并上传。文件变化、读取失败、取消或超限不进入恢复确认。导出先从同一任务下载到私有文件并验证大小/SHA，再交系统保存；保存取消不结算原导出任务。必须核对当前锁定的 file_picker 原生实现是否支持文件路径流式写入；若移动端只接受完整 bytes，则用 Android SAF 的原生文件流桥接，不继续扩张 String 接口。

ServerApi 增加流式上传及写入指定私有文件的下载方法，复用原认证、不可变权威代次、请求取消和超时、禁止重定向与有界错误响应。导入前缀为 `/api/v1/management-backups/imports`；同一原键不因断线自动 POST 第二次，未知时只查询原请求。下载不解析整个NDJSON；服务校验备份格式，App核对传输摘要。

服务器须提供真实配置上限及协议能力，App使用协商值，不能硬编码默认可传64MiB。当前默认仍32MiB，服务已允许显式64MiB配置并有实际39MiB网络恢复证据。App、公开能力与服务器说明一起完成之后才开放 `backup_v2`。

## 预览与确认

导入任务成功后读取标量统计（两套标签、视频、图包、页、阅读、回收、历史），根按24条分页。编辑保留草稿；逐根选择映射或“不启用”，最多256根。建议路径仅供参考，必须展示当前选择；相互冲突、越界、停用和找不到路径均有对应结果，不拿导入旧缓存当本机可用证据。

确认明确“完整替换管理数据、保留媒体字节、先保存恢复前快照”，确认默认关闭。持久保存 preview、映射、原 request_id 后才能发送唯一恢复 POST。任务运行可离页，重新打开只查询原结果。完成后沿用现有免口令新代次连接，返回媒体库；由于恢复清除了扫描证据，需要明确处理恢复后的重新核对/同步及准备状态，不能标记一次并未发生的扫描为成功。

## 历史与兼容

旧工作日志保留原epoch和协议。完整历史请求用 `/api/v1/management-history` 的原epoch或graph_id，任务与成员必须同图；不存在的代次或原任务不能查询另一图来“补齐”。本机仍保留的原备份控制任务和文件继续可读，异机文件缺失不声称能够重新生成原字节。

默认任务历史列表与当前本机备份控制记录不重复；显式原图仍完整。旧永久删除清单/页明细的只读路由，以及默认值、阅读请求等旧专用GET仍需审计；已有通用8类原回执入口不能代替页面实际接线。历史详情隐藏执行按钮，历史选择不进入当前删除流程。

## 验证顺序

1. 文件/HTTP网关覆盖分块、超限、取消、断线、SHA不符、私有文件消失、迟到响应、保存取消与原日志未知。
2. Repository 和页面覆盖 v1原日志、v2两类统计、跨页映射/冲突草稿、确认默认关闭、唯一POST与原GET、原epoch历史及恢复后准备状态。
3. Android真实系统选择/保存（含取消）、大文件、活动恢复、实际安全存储强停后新PID重开，在390普通和360双倍字号核对冻结原型。模拟保存器不能替代系统文件选择器验收。
4. 记录固定源码、请求轨迹、输入/源文件SHA、服务任务和截图；之后继续LF8全原型暗色/横屏/手势、其它命令强停组合、历史图片失败根因和目标设备/NAS验收。正式服务与签名升级另有发布步骤。
