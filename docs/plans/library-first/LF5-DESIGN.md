# LF5 图包阅读模块的实施契约

沿用冻结原型，不重新设计方向。LF4的图包详情将被真实阅读route替换；来源页继续持有查询、稳定ID/邻居和行内偏移。整包标签仍使用已有独立图包编辑入口。原型目录不参与生产构建。

## 服务端模块

`Reading` 持有固定成员、当前位置、进度、每包偏好、首次默认与实际最近的规则；HTTP层只验证输入并转入同一模块。直接从真实数据库接口测试这些行为，不在界面各处重复判断。

- `POST pack-sessions` 在同一事务求值完整的搜索、目录、标签交集、阅读状态、来源与排序；默认顺序，可显式随机；保存整包成员快照。当前页已加载24项不限制本次范围。候选超过五万明确要求缩小范围，不伪装截断成功。
- `GET pack-sessions/{id}` 返回当前可读包、相邻成员和可用数；`entries` 按固定原始顺序分页，失效项明确标注。编辑标签或新增包不改变成员；停用/失效只移除当前可用性。当前位置失效时就近选择仍在原范围内的项，GET不写历史。
- `PATCH position` 用会话revision与request_id更新手动选择或范围结束。不越界添加候选，不在纵向滚到底时自动调用。创建新会话会替换单用户当前阅读归属，旧会话写入被拒绝；读取旧队列不重新激活它。
- 首张图片实际显示后才 `POST opened`，携带包/页/清单版本、会话revision、进度revision与request_id；若当前项失效，实际打开候选时才提交回退位置并返回新的session_revision，原项恢复不会抢回阅读器。原子更新去重最近、初次进度、首次每包偏好及当前打开归属。建会话、读清单、缩略图与预加载不记最近。
- `GET pack-reading-requests/{kind}/{request_id}` 只读查询创建/打开/位置/进度/偏好/默认的回执；未知回执返回404，不自动重新提交，不重新激活旧会话。
- 后续 `PATCH packs/{id}/progress` 保存pageId、页内比例与完成状态，必须属于当前实际打开的包/会话/位置，且清单和进度版本均匹配。重复request_id返回原回执；冲突先重读，不盲目覆盖。切包、离页和后台先节流flush，再改变位置；UI必须按归属拒绝迟到回执。
- 每包 `preferences` 独立revision，包含模式、方向、间距、适配；全局 `reading-defaults` 使用另一revision。只有未设置包使用当前默认，首次实际打开时固定到本包，修改默认不会影响已读包。偏好写入本身不记最近。
- `GET recent?kind=pack` 与视频独立，只读实际打开条目；`packs`/`selection` 的 recent 来源和 recent 排序使用同一真实查询。可用性/目录/标签/名称/阅读状态过滤不扩大为全库。

Schema0009在原有表上增加进度content_version、recovery_reason和偏好revision；旧进度版本从对应包补齐，原pageId/比例/完成/进度revision与偏好保留。扫描删除续读页后选择最近可读页、清零页内比例、递增进度revision并保留page_removed说明，实际打开后才确认清除。当前页仅损坏则读取时返回page_unreadable和附近可读页。沿用迁移前快照、恢复写入门禁；完整管理备份v2和跨恢复代次隔离仍由LF7完成。

## 客户端接线（接口已接入，会话与界面待实施）

`04f57a8` 的类型化PackReader句柄已绑定连接/阅读元数据代次，独立取消读取，校验真实分页与回执；不可变ReaderCommand使未知写入可先只读查询。确认恢复前发布时递增代次并销毁旧句柄，isCurrent可供界面识别归属。

`PackReadingSession` 独立于视频播放器；有限窗口缓存分页页清单和队列摘要，使用同源鉴权、连接/包/清单代次及可取消读取。首帧解码后确认opened，再允许进度flush；回执丢失保留原request_id显式查询/重试，不能默默发新写入覆盖。

横向只保留当前及相邻图片，按显示尺寸解码；方向/适配/缩放与轻点显隐沿用原型。纵向已知宽高占位和惰性拼接，保持pageId+页内比例，切模式仍在同一图片。总览缩略图分页、页码跳转、沉浸退出和单页失败重试/跳过均必须接真实清单。图片缓存按字节有界；500页/4K/8K原生内存和延迟验收不能由元数据测试代替。

全局默认与每包设置分别写入；后台/离页flush可失败并保留待保存状态，旧包或旧连接响应不能改变新阅读器。实际阅读更新库的阅读状态和图包最近；返回通过LF4定位模块重新查询，不扩大来源或自动换包。

## 当前边界

服务端与客户端HTTP接线已实现，尚无阅读会话/阅读UI、真实图片内存/手势验收、设备联调、正式备份v2或新版APK。LF4与LF5 issue保持开放，完整原型对齐最终由LF8验收。
