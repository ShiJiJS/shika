## 接下来两条明确的本机操作

这些是当前能指出具体缺口的操作，执行后再对照原45项判断；本页不是将完整范围缩为两条。若发现新的缺口，应引用原ID、具体触发和缺失证据，不能仅以“更多组合”不断扩展。

1. **L1，视频范围末尾（PRE-02）。** 用当前普通第28版，从筛选范围中的指定视频进入；核对固定成员，分别操作顺序/随机、到末尾后退出/重来，确认不跳到范围外，返回保留来源。不重测未变播放器解码器或重复全部标签/后台矩阵。
2. **L2，深列表实际旋转（NAV-02、UI-05）。** 在超过120项的当前普通包列表中改变Android实际方向和系统字号，核对同一卡片/相对位置，进入内容再返回；读回两类型条件和范围。现有组件旋转、code25阅读器旋转和code28固定竖屏长列表记录各自复用，不能混称已经完成这一过程。
