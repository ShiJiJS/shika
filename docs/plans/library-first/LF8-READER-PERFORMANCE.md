输出原始profile结果、宿主内存/服务资源/网络路径、截图、源文件前后SHA与只读复核。原型保持独立不改，不正式发布/部署。目标手机/NAS的首帧、翻页p50/p95、内存及CPU/IO/网络仍待实测；本地无OOM不关闭完整READ-06。
