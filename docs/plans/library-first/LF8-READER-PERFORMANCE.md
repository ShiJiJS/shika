# LF8：复杂摄影像素的长包与重复计时

基于PR #95，继续READ-06及READ-01–05，#24/#33不关闭。现有三轮500页证据采用高压缩纯色图、debug构建，本段补充高细节/较大JPEG、profile模式实际UI操作的重复测量；不拿本机替代目标手机或SMB性能。

夹具由两份公开NASA/JSC摄影原图（iss043e000030、iss043e010521）以原像素裁切拼接，加页码标记生成；500页长包中400页4000×6000、100页8000×8000，另各3页4K/8K包。固定来源/下载SHA和生成参数；明确是两张摄影图衍生的506页压力样本，不是506张独立摄影图。素材仅放.dev、只读挂载，不访问真实图包。

复用当前生产lib、正常服务runtime preview.2，单独的profile集成入口和测试驱动收集数据；开发测试APK不替代正式安装包。运行于新建自有Android36 AVD/5558、独立8773数据与8774宿主采集控制，测试控制不改服务响应。保留构建类型、设备/GPU/视口、真实图像字节数和所有失败。

先跑通测量；发现问题则修复后冻结重跑。最终同版关键路径三轮：每轮4K/8K各30次从库点击到当前解码图像进入绘制树/帧结束的墙钟，注明8ms采样及输入注入/测试调度开销。每次关闭旧阅读器并清Flutter图片缓存；服务OS文件缓存不清，不能称整机冷读。记录原始样本及p50/p95，不任意删掉慢样本。正常相邻预读下翻页另记，不能当冷解码。

从库打开500页，真实纵向拖动覆盖全部页、横纵切换保留页、全程固定范围不自动换包；记录元数据120、ReaderImages最多6项/48MiB估算、实际图片缓存/帧时序、独立进程内核PSS/RSS和VmHWM。只在自有AVD启用adb root以只读采集/proc，避免dumpsys meminfo向App触发GC；内核PSS不含额外memtrack估算，采样PSS峰值不是瞬时峰值，VmHWM为该进程RSS高水位，provider估算不是进程内存。普通release安装包还需独立复核入口/阅读；profile指标不冒充release或目标机门槛。

输出原始profile结果、宿主内存/服务资源/网络路径、截图、源文件前后SHA与只读复核。原型保持独立不改，不正式发布/部署。目标手机/NAS的首帧、翻页p50/p95、内存及CPU/IO/网络仍待实测；本地无OOM不关闭完整READ-06。

调试测量器可显式使用run-reader-performance.py的--long-diagnostic：仅各一次小包准备，仍实际走完500页；输出final_matrix=false，正式汇总器拒绝把它当最终验收。用于定位跨元数据窗口的采集时序，默认/最终三轮仍为每类30次，不缩减最终矩阵。
