# LF8 第一轮：共享布局与实际渲染基线

本轮继续用户已确认的 LF-2026-10-23 完整原型，沿用 Paper。目标是让媒体库决定范围，内容从库或标签进入，返回保留来源。本轮修正共享尺寸和设置密度；不重新设计产品。

## 基线与坐标

冻结参考仍为 `design/reference/library-first/`，树 `1cbf605af8f03fa067a4ce8e914bb809e3a487ca`，独立可移除。生产 App/服务不导入参考源码或素材；本轮测试导出器是显式调用的可选工具，后续移除参考时可一起移除。公开花卉视频来自既有 App 资源，24张植物 SVG 来自冻结参考，另在本机导出900px以内PNG。原图包、NAS媒体和正式8760未使用。

HTML参考窗口390×844含底部12px的模拟系统区。实际Android录入窗口390×905，实测顶部49dp、底部24dp的系统区；去掉这些系统区后为390×832，正好与参考移除12px模拟区的390×832比较。保留全部原始ADB截图、真实前台窗口与MediaQuery度量；没有把整张Android截图拉伸到844，也没有在App添加假home indicator。3倍像素只在对照副本降采样为逻辑像素。大字号及横屏按各自实测安全区记录，不冒充这组精确对照。

每次参考导出在同一Ego调用内设置390×844/DPR1，等待字体、图片和有限CSS过渡完成。跨CLI调用视口覆盖会消失；初次错误尺寸、初次未等待主题过渡的文件仅属开发诊断，不进入正式参考。原生截图采用等价的并排、叠加和差异图；网页截图器不能直接采集原生App。

## 变更

- `MediaCatalogSearch`复用两类媒体库：55dp搜索区、42dp普通字号输入框、16dp文字，左边筛选动作保留触控区域，输入框x60、右距16。系统大字体增高，不缩字。
- 范围工具条60dp；视频预览范围按钮补回播放图标。卡片继续完整显示横竖封面，不裁视频内容。实际最终CSS和渲染也保持这种留边；初看较早CSS规则误判为cover，已纠正。
- 顶栏/分类左距20dp；导航按钮在300dp内居中，以颜色和字重表示选中，去掉原额外短横线。Android安全区继续由系统处理。
- 设置分组从原通用note+额外间隔改为专用分组间距。重复入口行采用22dp图标、13dp间距、15dp标题和12dp说明，自然换行且最小64dp。普通两行约70.4dp，字体增大时自然增高。
- 两个设置开关复用PaperPreferenceSwitch：只缩可见轨道至约40×24，整行至少64dp可点，原生Switch、原回调与存储保留；整行还支持键盘与单一开关语义，内层不重复接收焦点。相邻说明改为“前后各一条；关闭可减少网络与解码占用”，普通字号不再出现单字尾行。备份说明按backup_v2能力显示，不把未开放能力写成已经可用。
- 视频/图包标签确认区复用32dp信息行，主操作44dp，移除Material默认额外触控留白的视觉占位；清除/查看结果仍为显式次要动作。标签搜索去掉明显绿色填色；截图等画面空闲后采集，避免把暂时的点击涟漪当成选中背景。

## 复跑

先复用当前Ego工作区及页面导出公开输入，不能为页面暂时超时擅自新开工作区：

```sh
python3 scripts/prepare-prototype-fidelity.py --space <现有space> --page <现有page> --output .dev/<新的输入目录>
python3 scripts/run-prototype-fidelity-test.py --reference-input .dev/<输入目录> --output /tmp/<新的运行目录>
```

每次创建全新8768隔离容器和DB，实际扫描2视频/4包/24图，运行既有emulator-5554，`--no-uninstall`；最后恢复原尺寸/密度/字号并只删除自己创建的容器。8761–8763及用户现有原型预览不重启。`--width/--height`指系统窗口，内容区以导出的MediaQuery为准。不会输出或使用生产凭据。


## 视觉复核

独立存量评审两轮，不打分。首轮指出设置开关/说明密度、标签确认区多余留白与暗色首帧不稳定；已修正并由同一评审者逐项复核。正式取证在实际主题颜色稳定及界面空闲后进行，不能仅看偏好布尔值。先前未稳定截图和屏外懒加载前置失败保留为诊断，不计入正式成功轮次。两条新增组件检查验证整行/轨道/键盘各触发一次，以及禁用语义无激活动作；没有以样式常量镜像作为测试。

固定App/最终原生取证源码为a9da395；正式普通三轮与两种更短窗口使用同一源码。完整原型尚未验收，通过项及剩余工作见RESULTS.md和本目录证据。
