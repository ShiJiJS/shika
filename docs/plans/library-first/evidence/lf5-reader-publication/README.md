# LF5 阅读结果发布时的归属检查

`f43a320` 在异步返回、回执未知结果及同步publish通知之后再检查句柄归属，避免页面在通知中退出/恢复/换连接后，旧句柄仍返回可当作成功的新状态。新增用例让监听者在publish时销毁句柄，要求结果为RequestCancelled，服务端已确认的创建仅一次且仍可查询回执。

当前全量 **180项客户端测试**、Flutter analyze通过（含9项新阅读HTTP适配用例）。[日志](client.log)、[静态检查](analyze.log)、[源码/原始及公开日志SHA-256](results.json) 随提交保存；公开日志仅移除终端行尾空格，源码逐一匹配实现提交。179项的前一接线记录仍保留在 [adapter证据](../lf5-reading-adapter/README.md)，不能把它当作本修正的完整证明。
