## 诊断边界

`diagnostics`保留输出basename碰撞、初始观察把正常404当异常、旧驱动两轮成功及第三轮失败的日志／源码／请求。第三轮的直接repository旁路读回与界面共享取消域，造成测试观察干扰；现已改为独立API观察。失败退出还暴露上述生产生命周期缺口，后用四项控制时序回归独立复现。`checks`同时保留新测试最初缺少类型导入、错误等待持续加载动画的两次测试搭建记录；只有`lifecycle-red-valid.log`计作有效旧码四败。
