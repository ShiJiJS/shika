# LF8 独立截图评审

评审类型：存量已有界面润色，只对齐已确认的 Paper 规范与冻结原型，不打分。

## 速查清单

- [必须修正 1] 短横屏阅读设置：底部「继续阅读」只露出绿色上沿，文字消失 → 在 844×390、真实 SafeArea 下完整呈现可识别的返回阅读动作，不能留半截按钮。
- [必须修正 2] 双倍字号阅读设置：两处下拉框的浮动标签侵入前一个控件的下边界 → 保留系统字号，让标签、上一个控件和本控件形成独立、清晰的间距。
- [提升 1] 双倍字号普通阅读来源行：显示为「媒体库 · 全…」 → 在不挤压页码与下一包、不缩字的前提下，更完整保留当前来源含义。
- [提升 2] 短横屏范围面板：当前截屏没有显示底部翻页状态 → 有界内容的结束位置和分页状态应更容易发现；不据此断言分页不可操作。

## 范围与判断边界

整份读取了 `LF5-UI-DESIGN.md`、`LF8-READER-CHROME.md` 与独立评审手册。查看了三组提供的八态截图（paged、settings、vertical、immersive、restored、range、quick、quick-exit），以及六张冻结原型截图和相应几何 JSON；读取三组 `metrics.json` 辅助定位。没有查看实现源代码或历史评审。

以完整原图判断构图，接触表仅等比缩小以比较状态，没有拉伸原生系统区域。原生 390×905 的可用高度由真实上方 49dp、下方 24dp 系统区域独立划分，未强行压成原型的 390×844。原生 vertical 第 4 张与参考第 3 张的画面差异不列为问题。

这份报告只能证明静态视觉和所呈现状态。跟手翻页、缩放、动画时长、滚动可达性、真实来源返回以及持久化续读逻辑没有在本次独立评审中动态验证。截图中的页码和状态字段一致，不能替代完整行为验收。

## 必须修正（按影响排序）

### 1. 短横屏设置面板留下半截主按钮

**证据：** `/tmp/lf8-reader-final-landscape/reader-settings.png` 中，说明文字下方只显示「继续阅读」按钮的绿色上沿，按钮文字完全不可见。对应 metrics 中该文案的布局框是 y=348.8–368.8dp，而截图中的设置内容可见边界约为 y=350dp。冻结 `landscape-readersettings.png` 中同一主动作完整可见。辅助局部图见 `landscape-settings-bottom-detail.png`。

**影响：** 设置结束后的主动作在当前初始面板里失去名称，半截色块也使面板显得被意外截断。顶部关闭仍可见，所以本报告不把它表述为「无法离开设置」。

**目标与验收：** 在当前 844×390、字号 1、真实系统安全区下重新截图，返回阅读动作的文字和完整按钮轮廓应清楚可见；若内容需要滚动，滚动边界也应成立，不能用一个无文字的半截按钮充当结尾。不得通过缩小系统字号、覆盖系统安全区或删除真实必要设置来达成。

### 2. 大字设置的浮动标签与前一个控件边界发生视觉冲突

**证据：** `/tmp/lf8-reader-v3-large/reader-settings.png` 中，模式选择换为两行后，「翻页方向」浮动标签压在「纵向拼接」控件下边缘附近；下一个「图片适配」标签又侵入前一个方向控件的下边界。`large-settings-detail.png` 可直接看见两个标签跨在相邻控件相接处。metrics 中「纵向拼接」文字框为 y=303–343dp，「翻页方向」标签框为 y=340.5–372.5dp；方向值框为 y=365–413dp，下一标签框为 y=414.5–446.5dp。这里不是声称两段可见字形大面积相叠，而是标签与相邻控件的归属边界不清。

**影响：** 字号变大后，各设置组连在一起，浮动标签仿佛属于上一个控件；这偏离 LF5 要求的系统字号保留与自然撑高。

**目标与验收：** 保留字号 2 和控件完整文字，标签不要侵入前一控件的边界。重新查看 360×740 截图和相同区域放大图，模式组、方向组、适配组三者之间应有清楚的分隔，不出现共享边线穿过相邻标签的观感。无需更换整套原生控件。

## 提升项

### 1. 精致度：大字来源可以比当前省略得更少

**证据：** 大字普通阅读的 paged、vertical、restored、quick-exit 底行都将「媒体库 · 全部图包」收为「媒体库 · 全…」；同组 quick 状态将来源独立排布后可完整显示。普通字号没有此问题。

**影响与目标：** 这不是阻断，来源和计数仍有可见锚点，但北极星特别强调返回原来源。可在现有排布范围内改善来源的完整性，同时保留「3 / 4」和「下一包」的辨识度。以字号 2 截图验收，不以缩字换完整。

### 2. 精致度：短横屏范围面板的结束状态不明显

**证据：** `/tmp/lf8-reader-final-landscape/reader-range.png` 已清楚显示四个图包，但没有显示竖屏里可见的「上一页 / 下一页」分页状态；对应 metrics 的两段文案 y=362.8–382.8dp，位于当前内容可见边界之外。当前只有四项，分页在竖屏也是禁用态，因此没有证据说明本次范围切换受到阻断。

**目标与验收：** 有界面板中列表与分页的结束关系更易辨认；在短横屏验证内容末尾或滚动到底后，分页状态完整出现，且不进入系统安全区。静态材料不能证明滚动失败，不要求为本项新增解释文案。

### 3. 设计感与动效

**设计感：无其他确认的提升项。** 此次是按冻结原型收拢阅读器，主要画布、纸白工具层、墨绿图标与衬线标题已经形成同一方向；不建议另加装饰、重做品牌色或替换字体。设置采用紧凑原生选择控件，和原型的图标大选项在外形上不同，但 LF5 明确允许原生控件，仅凭这个差异不判为必须重做。

**动效：未看到动效，不作质量结论。** immersive 与 restored 截图能说明工具有隐藏和显示的静态状态，无法证明 140ms 收展、跟手翻页、降低动态设置或系统返回优先级正确。

## 可删文字

无确认必须删除的文字。来源、计数、范围限制、模式名称和设置里的手势说明均有明确用途。图中的 `REFERENCE / … / SYNTHETIC` 属于夹具图片内容，不属于应用文案，不要求从界面删除。大字范围说明自然换行，虽然较长，但没有可证实的填缝内容。

## 保留点

- 保留普通竖屏「顶栏—画布—进度—四工具—来源」的顺序和左右锚线。普通字体标题 20dp、副信息及工具 12dp 与 LF5 一致；原生工具栏触控高度略高于网页参考有合理平台依据，不应靠压扁系统区来追像素。
- 保留短横屏完整画布上的浮动顶栏和居中 360dp 窄底栏。metrics 确认普通横屏底栏为 360×52dp，四工具及普通来源行没有继续占据横屏高度；快速整理使用 430dp 浮层并保留明确的整包标签、回收站和范围切换动作，符合 LF8。
- 保留大字四字工具按两字换行、图标上对齐、标题自然增高的处理。不要为了修正面板间距而缩小系统字体。
- 保留沉浸状态的画布优先级和右下页码，以及 quick-exit 恢复普通四工具的静态状态。纸白、墨绿、衬线标题与真实 SafeArea 的独立性均应保持。

未确认除此之外的必须修正项。本报告不打分，也不据静态截图宣称完整阅读、NAS 数据写入或来源返回已验收。
