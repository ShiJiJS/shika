# 视频控件减少动画修复

对应 #97、#24 / #33 的 UI-06。系统启用“减少动画”时，视频控制条、来源栏位置和全屏返回控件仍固定执行160ms动画。四处改为已有的 `MediaLayout.motion(context, 160)`；关闭偏好保留原160ms行为。

生产播放器四个行为用例覆盖内嵌自动隐藏、全屏轻点隐藏及系统偏好开/关。开启偏好时首帧即隐藏、来源位置移动34dp、全屏返回控件隐藏；关闭时核对首帧与80ms中间态、160ms结束态。所有情况保持播放。相同四断言针对隔离的旧 d5c865e7 模块为两项通过/两项失败（减少动画首帧仍为1），修正后四项通过；加上13项生命周期、播放意图与资源检查，共17项通过，两个文件analyze通过。

provenance.json记录旧模块、行为测试和日志原文件SHA；日志只清理控制字符。旧模块仅调整相对导入以便隔离加载，未覆盖生产模块。新修复未改变阅读器、后端或原型；当前正常预览APK尚不包含此修复。这里只完成播放器组件证据，不代表完整UI-06或目标手机验收结束。
