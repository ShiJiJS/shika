# LF8 图包库继续阅读：阶段证据

固定 App/原生取证源码 **c4aaf3b**，分支 `codex/lf8-pack-continuation`，基于 PR #58。本段补真实续读入口及原媒体库范围返回；LF8/#33和总任务#24继续开放。冻结参考树 **1cbf605** 独立未改，正式8760、NAS、SDK和发布版本不参与。

## 可观察结果

使用完整 VideoViewerApp、真实 ServerLibraryRepository、已有 emulator-5554 和每轮新建的8768隔离服务/DB。公开输入实际扫描2视频、4包、24PNG；只种已有页码，不伪造最近记录。首次进入没有续读条；从卡片实际打开第三张、解码第四张后返回，才显示“第4/6张”。点击续读从第四张打开，真实会话仍是当前媒体库完整4包，返回顶部。搜索结果、多选和最近页均无全库续读条。

摘要与封面读取前后核对完整进度对象相等；长错误失败与重试也不修改进度，图包列表保留。每轮两次显式阅读创建两条会话、两次实际 opened，最终只有一个最近条目和一条第四张进度。`PACK_CONTINUATION_VERIFIED` 中 `before_summary` 是第一次返回后的进度，`after_summary` 命名沿用测试变量、实际指第二次显式打开并返回后的稳定快照；两次真实打开之间 revision 从3到4是正常写入，不能把这两个字段误称为同一个只读区间。各只读区间相等由固定测试里的单独断言验证，最终稳定快照与最终读回完整相等。

请求日志保留路径/状态/阶段，两次创建范围额外保留公开样例查询体；不记录认证体、token或授权头。原生日志不含查询串，不能据此宣称已逐条核对 `recent/limit=1`；精确参数、取消通道和不写请求由真实HTTP客户端检查验证。故障夹具只拦截最近摘要，列表仍正常。

客户端471项通过，含5项新HTTP与7项新组件检查，覆盖独立取消、换连接晚到结果、失败重试/未知页码和深列表多选前后位置；三种组件窗口另加入很长错误说明的可达性检查。服务端7项新续读查询与9项既有阅读检查共16项通过，包含27包越过24条分页、真实打开顺序、拒绝旧会话迟到写入、完成包续读和不可用包排除；生产服务代码未修改。analyze与Ruff通过。没有把本段16项称为服务端全套回归。

## 渲染与取证边界

正式普通窗口三轮、大字与短横屏各一轮，每轮10个实际前台检查点，共50张原始ADB图。均为同一固定源码，`--no-uninstall`；每轮26个媒体源文件前后SHA相同，各轮一致，结束恢复原尺寸/密度/字号并只移除自己创建的容器。

正常原生390×905，实际系统安全区49/24dp，内容390×832；参考390×844含底部12px模拟区。`compare.py`仅移除上述系统区、按DPR3等比例降采样，产出同390×832的并排、叠加和差异图，不移动列或拉伸全屏。参考通过实际续读、翻页、返回形成相同4/6状态；采集时同一次Ego调用设置视口并等字体/图片/有限过渡完成。

参考续读条85dp；实际中文/西文混排回退字体的页码行19dp而非估算18dp，原生自然增高至86dp。双倍字号实际360×809，安全区45.333/24，续读147dp；短横屏实际844×442，安全区28/24，内容390dp高。大字和横屏分别按自身窗口检查，不冒充390对照。搜索检查保留真实键盘状态；打开“更多”后退出搜索焦点，非文字的多选/故障重试场景中键盘已收起，不把旧版仍显示键盘的截图称为最终版本。

两轮独立存量视觉评审不打分，针对续读区域与相邻布局。首轮773026a阶段材料单独保留；收键盘修正后，以c4aaf3b最终普通、大字、短横屏复核同一问题清单，无本段必须修正项。正常/大字没有重叠、越界裁切，重试可见；真实长文件名会省略，作者/标题拆分仍是下一段工作。错误说明刻意注入长输入以验证省略和重试可达，保留具体服务失败原因；省略属于已知阅读边界。没有为了改善图像而缩短压力输入。

本段沿用原路由过渡/加载/减少动态效果，未新增装饰文案或独立动画。静态图不证明点击或返回行为；原生测试的逐步点击与回读提供行为证据。没有手势/动画录屏，UI-06不关闭。

## 文件与复核

- `normal-1`至`normal-3`、`large`、`landscape`：50张原始图、前台窗口、真实文字/矩形、请求、源码SHA、媒体SHA及恢复配置。
- `database.json`：只读SQLite投影，仅包含公开样例的数量、页码、最近与会话来源；不复制认证表或整个数据库。
- `reference`与`comparison`：冻结参考实际渲染与可重建对照；公开素材SHA沿用[共享布局输入](../lf8-shared-geometry/inputs/)。
- `checks`：固定代码的客户端471项、服务端16项、analyze/Ruff原始输出。pytest的两条环境警告保留，不影响测试结果。
- `diagnostics`：原生字体溢出、短横屏键盘挤占批选区，以及诊断hook首次编译错误的原始日志/配置恢复。修复使用实际文字测量，正式轮次不忽略Flutter异常。
- `review`：独立视觉记录及正式压力窗口复核；静态与动作证据分开。
- `manifest.json`与`verify.py`：逐文件绑定，核对固定源码、50个图片/前台窗口、只读区间/真实打开区别、两次完整范围、SQL投影、源字节与设备恢复。它是本次固定版本证据；后续代码变化须按受影响路径重新验证。
