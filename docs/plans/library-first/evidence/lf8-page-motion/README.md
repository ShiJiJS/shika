# 页面进退场：系统偏好变化与三轮原生证据

对应 [#103](https://github.com/ShiJiJS/video_viewer/issues/103)／UI-06，基于 PR #102 的 `8dbb703f`。页面实现 `871a08b2`，标准 NavigatorObserver 接口 `fa11bc1f`，最终原生入口固定 `abbf2ca2c864c00de7eb54da164a4711ffee1182`。正常 code9 两包保持原 SHA，**尚不包含本段页面修复**，没有发布 APK 或部署 NAS。冻结原型树 `1cbf605af8f03fa067a4ce8e914bb809e3a487ca` 独立未改，仍可单独移除。

原实际媒体库进入图包的两个检查均读到 450ms，普通与减少动画均未落实约定。生产 13 个调用文件的 17 处页面创建统一使用 PaperPageRoute，正常进入 240ms／返回 160ms，减少动画为 0；返回时读取当前偏好。保留 Material 页面状态／返回结果／平台过渡，两处视频入口仍单独淡入，不联动缩放来源页；业务、播放器卸载／释放顺序及 route.completed 约定不变。服务生产树未改。

最终完整客户端 **687 项**、analyze 通过。10 个新增检查包含实际图包入口普通中间态／减少动画首帧，以及平台／淡入两种路由、进入与返回偏好的四个组合、来源输入与原返回结果；10 项属于全集，不额外累加。组件明确使用测试无障碍值，不当作系统接入证明。[原两个失败](before-tests.log)对应的[测试字节](before-test.dart.txt)与变更前保存的 SHA 完全一致。首次扩展检查的精确时钟边界和异步图片等待失败保留，修正等待方式，没有放宽 240／160／0 配置或减少动画首帧断言。

`native-4-layout` 从当前 VideoViewerApp 实际媒体库／设置页操作，真实 8777 隔离服务、公开两视频／三页图包及原任务数据。每轮在两种真实系统设置下分别进入图包阅读、视频预览、实际横屏、任务详情，打开后切换为相反设置再返回；四种页面各 6 组进出，共 **48 次过渡**，三轮完整通过。真实 Android window／transition／animator 比例、PlatformDispatcher 和 MediaQuery 核对，无注入；原生 Android input 点击／返回，首次全屏说明按明确 SystemUI XML 确认。图包实际解码并 opened 后才返回，视频范围／当前 ID 未变，返回原图包／视频库及原任务行均核对；单包、小任务夹具不代表所有长列表来源组合。

通过 NavigatorObserver 在 didPush 绑定实际 route，正常 App 默认观察器为空。ModalRoute.animation 是预排版可被强制为完成值的代理；本段只读 SDK protected controller getter（代码显式标注）取得真实进度，**没有修改 controller、时钟或系统无障碍值**。原始帧同时保存 controller 的实际 duration／reverseDuration、进度、显示代理和 offstage，避免用配置常量或预排版值冒充动作。

48 次均核对实际 controller 时长与约定；普通模式包含显示代理不在 offstage 时的中间态，减少动画首个记录帧的 controller／显示代理直接到目标。[额外只读核对](reduced-first-frame-check.json)确认 12 次减少动画进入的首个记录帧均 offstage=false、两种进度=1。普通进入的实际观测跨度 250–383.333ms，返回 166.666–183.333ms，保留帧间隔与横屏较慢观测；这些是引擎帧回调，不能称物理显示呈现延迟或目标手机速度。

18 段 MP4 含四类页面进出和系统设置切换，全文件独立解码通过，18 组开始／结束截图与窗口焦点均在 App。[独立复核](audit.json)直接读取全部原始数据，完整报告见 [profile-result.json](native-4-layout/profile-result.json)。原始进入／返回截图另有 48 张；它们记录动作当时的状态，**不是稳定画面的完整视觉终验**：阅读图片可能尚未到达，横屏可能正在系统旋转，一次全屏说明窗口抢焦点。上述空画布／旋转／系统说明均原样保留，[焦点审计](capture-focus-audit.json)列出例外；确认解码在截图后、返回前执行，不以空画布称加载完成。三张[第一轮](visual-round-1.jpg)／[第二轮](visual-round-2.jpg)／[第三轮](visual-round-3.jpg)汇总图只等比缩小和留白，不修图或抹除过渡，没有新增独立视觉评审。
