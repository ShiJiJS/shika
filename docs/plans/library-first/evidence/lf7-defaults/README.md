## 实际路径

隔离8761、API36 Android，每轮重新生成27个公开花卉图包并实际扫描，81张图片；通过正式接口实际打开一个包以冻结本包偏好，另建立一个随机视频预览范围。此后清空请求轨迹，开始设置流程。

设置→默认播放顺序：先读服务端随机值，展示设备旧顺序（顺序播放）；选择旧值仅改草稿，明确保存后服务端顺序revision变更。再次进入不再提示该连接的迁移，旧活动视频范围完整JSON不变。

设置→阅读偏好：改草稿后关闭，读取证明仍为原默认；再次编辑横纵模式、方向、间距、适配方式并明确保存。服务已保存但响应故意替换503，面板保留未知状态；明确查询同一原ID，仅GET回执，没有重发PATCH。旧已读包偏好保持，另一未读包继承新默认但尚未冻结为本包覆盖。

销毁并重新创建App/Repository，从生产安全凭据适配器的专用测试键恢复连接，从Android独立测试偏好文件恢复迁移决定及相邻准备开关；再次进入设置读回默认及迁移状态。这里是同一Android进程内的App/Repository重建，不冒充宿主强停进程。真实安全存储强停证据在此前恢复/永久删除阶段分别保留。

每轮5个检查点保存原生截图、真实请求和81张图片SHA。最终只有2次默认值PATCH（视频200、阅读503），只GET一次原阅读设置回执；没有视频范围写命令。原生测试另外逐次断言旧视频范围完整响应、已读/未读包偏好和本机文件重建结果。独立核对程序验证全部检查点哈希、取消前无写、原请求SHA对应及正式成功日志，不把测试自己打印的结论当作文件/请求验证的替代品。
