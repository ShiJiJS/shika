# LF4 图包标签名称与编辑读回

功能首提交 `5d0d49d`，本检查点实现/验证提交 `5821667`。每张图包摘要直接带独立标签名称，编辑/筛选原选择按ID解析；没有为每张卡片遍历全部标签或复用视频标签名。恢复发布前取消旧名称请求，整套备份v2和跨恢复代次验收仍由LF7完成。

主Agent通过项目脚本运行实际Android + 8761隔离FastAPI：27个公开花卉图包/81页，真实创建61个图包标签，第一包只关联第61个标签。验证卡片显示名称、按ID读取首50项外选择、故意503后手动重试、搜索时保留原选择、保存新增标签并实际读回、仍打开的详情重开编辑保留两项、标签改名/删除刷新卡片，同名视频标签不变。

本提交完整路径连续三轮通过：390×844、360×740系统字号2、390×844。每轮日志、host events、APK哈希和文件校验分别保存。390截图来自第3轮，大字截图来自第2轮；proof内使用原始取证文件名，公开截图按视口重命名，第1轮原图保留本地。两类视口的截图均来自实际ADB，卡片取证先等封面解码并滚动到标签完整可见，不修改App的卡片尺寸。

157项客户端测试和Flutter analyze通过；41项本次图包/类型/选择相关服务端回归及Ruff通过。其他阶段原有56项选择相关证据单独保留，不把本次41项冒充整个服务端测试集。自动测试另覆盖300项ID按256分批、错误/不完整协议拒绝、401失效、迟到名称不覆盖新搜索、换连接清除旧名称/禁止保存、已删除选择需取消后保存、长中文大字布局、筛选初选及原offset重试。

过程记录：一个旧协议测试仍精确要求旧能力集合，补入新增的catalog_selection和pack_tag_names后完整41项重跑通过，没有放宽断言。早期一次大字运行在受控503之前遇到传输失败，旧验证只允许一次手动重试，未覆盖这个故障序列；现脚本最多执行三次显式用户重试，每次保留原ID，且最终请求轨迹必须包含实际503及200。失败运行不计入上述三轮成功。

沿用已评审工作区/P2的文字与组件，标签行采用既有视频样式；本次未重新开独立视觉评审，主Agent看图核对普通和大字卡片/失败状态。没有新视觉方向或新动画，继承既有弹窗、选择和加载过渡。保存/改名截图保留实际滚动状态，不代表深列表返回定位已经验收。
