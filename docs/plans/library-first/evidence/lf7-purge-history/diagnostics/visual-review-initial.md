## 可见问题

### P3：目录根项的单独 `.` 对普通用户不够直观

**位置与证据：** `round-2/history-query-error-kept-page.png`、`history-result-next-page.png`、`history-directory-results.png` 中，可见 `原图包 23 · .`、`原图包 02 · .` 等目录结果；下一行标注“目录 · 已保留”。同组内另有“空目录”结果。

**影响：** 文件系统使用者能够理解 `.`，但在历史核对语境中，它更像缺失名称或多余标点。用户需要辨认究竟是图包本身被保留，还是某个未命名子目录被保留。这不阻断浏览，优先级低。

**修正目标与验收：** 可仅替换展示文案，把这类根目录的 `.` 显示为“图包根目录”或现有产品词汇中同义且明确的名称，不增设组件，也不改变真实路径。在普通字号和双字号下，根目录与命名子目录应能直接区分，名称与状态均能完整换行。
