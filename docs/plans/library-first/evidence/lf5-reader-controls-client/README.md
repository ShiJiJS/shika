原生专项首次发现：未放大时InteractiveViewer的scale识别器也会取得单指拖动，即使panEnabled=false；原有按钮翻页正常，手指翻页却被截获。现在图片层统一识别手势，将未缩放的单指拖动转交PageView真实ScrollPosition.drag活动，使用原滚动物理和RTL方向；PageView不再另注册竞争的水平识别器，直接拖动时保持子图片可命中第二指。出现第二根手指或已放大则取消翻页活动，由图片负责缩放/拖动。

这3项widget用例显式设置touchSlop=8（原生设备实测相同），已增加：手指按住时画面跟随约四分之一页、松手回弹原页、左右完整滑动、切到RTL后反向滑动和实际双指缩放、放大后拖动不换页、返回先复原缩放。随后仍执行原模式切换、纵向滚动、落盘/退出/续读和尺寸布局检查。真实图片资源首帧是opened依据，没有将预加载计为阅读。测试总数仍为197，原3项用例的断言范围扩大。[较低触控阈值专项](android-slop-regression.log)3项通过；同一阈值在修正前的3个尺寸均能复现双指失败，修正后没有删除缩放断言。
