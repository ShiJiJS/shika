# LF8 内容页强停与主动恢复

本阶段部分验证后按用户要求暂停。固定 `434278a` 的普通视频与纵向图包各一次真实双进程运行，每例七个 ADB 检查点，共 14 个认可点；不是每例连续三轮。reader／video 分别对应开发输出 content-reader-2／content-video-1。最终 `395bf7c` 仅加强驱动断言并调整全屏准备步骤，生产 App／服务／runner 与前一提交字节相同；verify.py 审计唯一差异为该驱动。全屏两份诊断均不计通过，仍待验证。18 项相关组件、最终驱动 analyze／Dart format 及 Ruff 检查见 checks，未重跑客户端或服务端全集。

生产改动仅将原 main 的窗口初始化抽成共享函数，原方向和系统栏配置不变。驱动在两个进程调用同一配置，再启动生产 App／Repository；独立安全凭据键与偏好文件支持免口令恢复。它没有调用正式 main 的默认凭据路径，不等于签名升级、正式安装或 release 构建。

## 强停与只读边界

第一进程从真实媒体库点开内容：视频初始化并实际播放、位置大于 100ms；图包真实解码、操作设置为纵向拼接，再拖动至第 4 张约 15.41% 偏移。宿主在内容仍活跃时执行 `am force-stop`，记录原 PID 消失；第二进程必须有不同 PID，启动在竖向媒体库且没有播放器／阅读器自动打开。原始第一进程工具输出含主动强停导致的失联、测试未完成或临时目录清理错误，原样保存；它不是普通成功测试，phase-0-exit.json 标记其性质。

第二进程先浏览媒体库与最近，再返回媒体库；尚未明确点开前，宿主冻结检查边界。七张表 playback_rounds／round_entries／recent_entries／pack_sessions／pack_session_entries／pack_progress／pack_preferences 与强停后逐行相同。只读阶段所有新增请求均为 GET，没有视频 stream 或阅读 image；缩略图读取可以存在。独立保存请求前缀、增量与 SQL 快照，确认后宿主才放行重开。强停前后两次快照分别保留，以强停后的数据库为冷启动比较基准，避免把强停瞬间合法完成的回执算作恢复写入。

## 主动重开

普通视频回到同一 video_id，显式选择新建范围，实际播放器重新播放；只读阶段保留原范围和最近记录。现有协议不保存播放秒数，本阶段不声称按秒续播。普通视频强停前与重开后有真实窗口截图与像素检查，固定样本无绿边；不据此关闭其它解码路径的 #78。全屏诊断虽实际横向打开、强停与新进程竖屏恢复，但捕获的当前视频已变为下一条，不认可目标身份验证。

图包重开后同一 page_id、index=3、纵向模式、offset_ratio=0.1541025641025641，四个画布相对几何值逐项在 2dp 内，当前图已真实解码；截图可见合成图 04 和 4/6。新阅读范围／最近时间／进度 revision 是用户明确打开后的合法写入：progress 的页、偏移、完成状态与内容版本保持不变，revision 增加一次。`before-stop.json` 中通用 recent API 默认读取视频，图包最近另由七表快照的 pack 记录和实际最近图包页面证明，不把空视频最近误写成图包最近为空。

## 环境、诊断与边界

成功与诊断均使用专用 8768 可丢弃服务、4 个各 6 页公开合成图包加 2 个公开视频（26 源文件）；成功轮前后 SHA 相同。API36 ARM64 专用 AVD，软件 GPU、GLDMA off、宿主 AVC2；普通 390×844、字号 1，全屏诊断截面为 844×390。各轮恢复原显示，最终关闭专用 AVD 并记录宿主 PID 消失。

首轮 `158c11f` 在只读导航时，脚本误以为最近页的图包类型也会切换媒体库，等待图包库超时。实际两入口按设计独立；仅修驱动显式切换媒体库类型，未改产品逻辑。失败材料在 diagnostics/independent-kind-driver，不计成功点。组件与生产代码相同，最终静态检查针对修后驱动；原型树 `1cbf605` 未改，独立且可移除。

全屏首份 diagnostics/short-clip-advanced 的原始 runner 曾显示通过，但独立核对发现 5 秒样本在捕获前已换到下一条，review-verdict.json 明确拒绝该证据，原输出不改写。395bf7c 加入强停前后相同目标断言并尝试暂停后旋转，第二份 diagnostics/short-clip-identity-guard 在准备结束的目标身份断言失败，尚未实际强停。不据此定性为产品恢复缺陷，后续需隔离短样本自然结束与全屏准备时序。用户要求暂停，本轮不继续扩大测试。

执行 `python3 docs/plans/library-first/evidence/lf8-content-restart/verify.py` 只读核对 manifest、入库状态、固定源码、截图／窗口、PID、只读请求与七表、明确恢复、媒体 SHA 及环境恢复。此专项不等于更多断线／来源／格式／主题／字号组合、完整手势录屏、目标手机／真实 NAS 性能或发布验收。按用户要求本阶段收尾后暂停，#24／#33 保持开放。
