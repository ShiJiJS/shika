# LF8 共享布局：真实原生/参考对照（局部验收）

正式源码 **a9da395**。普通390窗口三轮、360双倍字号和844短横屏各一轮，均运行完整VideoViewerApp、真实ServerLibraryRepository与新建8768隔离服务；每轮8个检查点，共40张ADB原始截图。这里只补UI-01/03/04/05的共享区域证据，**不关闭完整LF8**。未改冻结原型、NAS/正式8760、SDK或发布正式APK；运行的是调试集成测试，旧App安装与现有AVD保留（--no-uninstall）。

## 可观察结果

- 同一公开输入实际扫描2视频、4图包、24PNG；不是一张图一个媒体条目。每轮26个源文件前后SHA相等，五轮相同。SQLite只读投影同时核对数量；最近未伪造为实际打开。
- 媒体库搜索、工具条、顶栏/类型左距与居中导航对齐：普通内容坐标搜索框[60,97,314,42]，首行封面上沿207、卡片标题426、导航上沿782。两类目录仍独立搜索/标签；标签真实选择户外，读回匹配2项后采集。
- 设置三组标题为68/251/503dp，入口行可读；设置开关约40×24可见尺寸，整行最小64dp可操作且支持键盘/单一开关语义。普通说明无单字尾行，页底阅读偏好可达。大字、暗色、短横屏均未报Flutter异常。
- 真实主题色稳定后才采dark；verify.py独立核对原始PNG中实际背景像素，不用开关状态冒充已渲染暗色。
- 16项针对组件检查通过（含窄屏键盘/大字/横屏、分页选择、标签分页/设置，以及开关指针/轨道/键盘各一次和禁用语义）；analyze与Ruff通过。纯UI修正未重跑服务端/全部业务全集；旧全集只能作为历史阶段证据。

## 图像与坐标

`reference/`为冻结代码实际渲染的390×844/DPR1，含12px模拟系统区。`normal-*/`原始ADB为1170×2715/DPR3，实际MediaQuery窗口390×905，安全区顶部49、底部24。`comparison/`只移除这两个真实系统区，3倍采样转成逻辑像素，并移除参考12px假系统区，得到同尺寸390×832；不拉伸整个画面，不移动卡片列，不把参考资源写入App。

保留原始窗口截图、前台焦点、全部MediaQuery矩形/文字、源码SHA、请求日志、源文件SHA与恢复后的设备配置。`compare.py`可重建并排（左参考右原生）、叠加及差异图；不是用同一个全图阈值宣称还原成功。字体栅格/Material图标差异和原型功能缺项人工分开判断。

360窗口的系统切口按宽度缩放，实际安全区及约740dp内容高度见各轮metrics.json，不改系统字号来凑截图。844横屏使用更短窗口，实测内容390dp高。它们是补充压力场景；widget检查也覆盖360×740、844×390等精确逻辑约束，不冒充目标手机性能。
