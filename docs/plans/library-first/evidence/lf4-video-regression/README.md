# LF4 当前工作区的视频原生兼容复跑

在 `b25ab04`（产品代码为 `be7be51`）上，使用实际Android与8761隔离FastAPI复跑既有 `--preview` 完整路径，一轮通过。该记录补充图包定位后的旧视频兼容检查，不替代LF3的I2两阶段、进程重启和其他原生能力验收，也不作为LF4全部完成。

真实媒体库名称搜索匹配25个视频，初载24项；显式进入固定范围并由原生播放器播放，长按临时2倍后恢复；队列切顺序、选择第25项、末尾提示与范围内重新开始。返回释放全部解码器并保留原搜索，只有实际打开的视频进入最近。再显式进入横版新范围，暂停后进入/退出横屏仍保持暂停，再返回释放解码器。全过程最多3个解码器、至多1个有声播放；测试逐步断言原生状态和真实接口结果。
