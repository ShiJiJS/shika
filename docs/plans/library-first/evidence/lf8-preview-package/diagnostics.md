# 本轮诊断与界限

旧APK连接独立服务时，ADB Ctrl+A没有替换Flutter字段，而把新地址追加到默认地址后。App在HTTP前拒绝了无效地址。改为按实际字段长度删除、先断言字段为空再输入，最终连接成功。原默认地址／输入中的口令截图保留本机，不放入正式证据。它是输入脚本问题，不宣称修复App问题。

首次清理已关闭独立5556与新服务容器，随后因旧服务容器名与新服务前缀不同触发归属断言并退出非零。读取原创建元数据、核对准确容器ID／名称／项目内data挂载后移除剩余容器；最终cleanup.json为成功记录，原四服务ID与运行状态前后相同。不把首次清理当完整成功。

旧服务0004没有固定视频会话／图包能力，因此新版按既有兼容约定进入旧视频UI，连接后自动播放也属于此旧兼容模式；“启动进媒体库且不自动播放”的证明只适用于配套新服务。没有向旧服务请求图包API，不伪造旧服务图包支持提示。
