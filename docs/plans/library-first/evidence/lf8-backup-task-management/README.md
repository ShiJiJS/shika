## 实际流程与证据

`normal/large/landscape` 各13点：普通390×844、双倍字号360×740、短横屏844×390，实际DPR3。经设置进入旧备份，取消／保存、只校验一次、预览未确认取消、真实IME、格式错误；之后准备27个真实图包任务及81张源图片，再清零任务阶段请求。原请求只GET一次，原备份下载两次分别取消／保存，历史任务只读，任务阶段零POST。前6点尚未种入公开图包，源图片列表为空；后7点的81张源SHA相同，不把准备阶段的写入称为只读。取消／保存用注入的文件边界，不冒充系统选择器。

`archive/normal/large/landscape` 各8点，共24点；与上述39点合计63个最终原生前台检查点。仅使用已运行的独立8762公开夹具，从真实App设置入口导出、校验私有临时文件、逐页核对27目录，明确确认一次恢复，再查看恢复前快照而不确认第二次恢复。原生断言实际管理epoch更换、导出后新增的视频／图包标签被替换、当前恢复任务完成及快照身份；请求记录分别只有一次导出、一次文件导入、一次恢复和一次指定快照预览。每点及前后源文件精确SHA相同。`host-events.json`只取epoch，不把夹具历史强停任务指针当本轮恢复证明。

每轮包含原始PNG、前台窗口、真实窗口／系统字号／安全区／键盘日志、请求、源SHA与固定源码。每轮结束恢复原1080×2400／420dpi／font1.0。v2测试使用Android私有文件的流式存储边界，未打开生产backup_v2，也未替代系统文档提供器或大文件／故障门槛。
