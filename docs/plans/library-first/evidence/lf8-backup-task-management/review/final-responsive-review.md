## 可见性、换行与裁切观察

- 大字页头随字增高，已显示的备份页、列表页与详情页标题、刷新和关闭图标均可辨，没有标题挤压图标或横向截字。备份介绍、取消状态、历史只读说明、任务编号可换行，未见省略号替代内容。
- 大字恢复摘要把“回收站 1”中的数字 `1` 排到下一行，数字仍完整显示，摘要容器随内容增高；只记录该换行，不追加摘要构图调整项。当前短目录 `/media/shorts` 和子项路径均可读，不能代替极长目录换行证据。
- 大字任务列表首帧只容纳一条完成任务；分页图为正文末段，能看到总 27 条、2/2 页及分页动作。这符合交接的同一正文滚动约束，不要求筛选与分页同时停留在一帧。
- 短横屏列表五类筛选可在一行显示，第一条记录的名称、状态、数量和日期可读；详情、历史说明、编号与路径均在可见帧中保持横向完整。
- 多张图已处于正文中途或末段，出现页头下接半段正文、底部接未显示完整的下一段等视口边缘截断。这类帧不能据静态图认定永久裁切。当前可见的完整字段 / 筛选控件内部，没有观察到文字被自身边框切断。
- 取消 / 保存提示在大字与短横屏会覆盖一部分下层正文，但提示文字自身完整。该帧不能判断提示停留时长或消失后可达性，不把临时提示下的内容遮挡升级为新改版项。
- 大字恢复键盘帧显示第一焦点目录、原目录、第二目录标签和底部动作；短横屏键盘帧只有恢复页头与第一焦点字段露出，底部动作不在画面内。真实键盘已经占据屏幕，但此证据不验证剩余正文与动作能否滚达，也不要求极短键盘高度下固定容纳全页。
