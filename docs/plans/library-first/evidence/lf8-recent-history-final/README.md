## 真实流程与不变量

每轮使用独立8768服务、两个公开视频、四包24张合成花卉PNG。从媒体库搜索真实播放后，最近只有已打开视频；从最近进入的首个播放范围只有1项，未扩大到库中另一视频。随后打开第二个视频，最近倒序两行；图包分别从媒体库打开后，最近两包范围与服务端会话成员/序号一致。实际视频和阅读器均等待首帧，夏日祭从保存的第3张续读。

两类最近各注入一次GET 503，保留旧列表并通过真实重试按钮恢复；故障到重试之间只有读取请求，图包完整进度对象（含revision/更新时间）前后相等。媒体库保留各自“风里的花园”及“夏日祭”搜索草稿。每轮请求、SQL只读投影与日志分别留存；无回收操作、无扫描，26份源媒体SHA前后及跨轮相同。

键盘两图均等待实际非零 `viewInsets.bottom`，检查隐藏导航和搜索可用；大字原生还断言整个视频按钮/图包快速整理按钮落在键盘顶以上。组件四种键盘组合验证两类搜索及关闭恢复；新增两项大字检查在旧实现均失败、修后通过。旧实现回放和 IME 尚未可见的早期失败在 diagnostics 中单列，不计99点。

短横屏最近视频首行上部不在视口内来自先前条目的位置恢复：实际 `scrollOffset=98`、`listHeader=52`、`stride=111`；错误区插入后偏移仍为98。该状态保留先前“风里的花园”锚点，不强行回顶部。
