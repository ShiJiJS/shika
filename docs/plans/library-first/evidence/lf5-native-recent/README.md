## 实际路径与断言

27条历史由专用夹具预置，不算作本轮实际显示。先在媒体库保留一个无匹配搜索，再实际打开此前未读的一包、显示首帧并保存第二张，最近成为28包；没有阅读的45包不会加入最近。进入最近不继承媒体库搜索，按最近阅读排序；真实行显示第2/3张。

滚动越过首批24项，到末尾全选得到完整28个最近ID。点击末尾历史包，实际首帧从保存的第二张续读；会话范围仍为这28包、当前位置27，opened使历史重排也不扩大或重排已冻结的阅读队列。返回保留原视口锚点和行内偏移：先补齐所需的尾页，再恢复位置；重排后仅允许完整列表的合法底部夹位，锚点部分可见时仍核对与视口重叠。切回媒体库，原无匹配搜索和0结果保留。

本轮只有2次创建阅读会话和2次实际opened；预置27条历史与本轮首帧明确分开。分页offset24、全选ID、来源、排序、完整筛选、会话队列和落盘进度均有断言；请求快照不含鉴权头或请求体。
