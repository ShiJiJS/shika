# LF5 客户端阅读接口接线

实现提交 `04f57a8`。全量179项客户端测试、Flutter analyze通过，其中8项新的真实HTTP适配用例。本轮没有阅读UI或新的Android截图。日志、已提交客户端源码/测试/依赖的SHA-256见 [results.json](results.json)、[客户端日志](client.log)、[静态检查](analyze.log)。公开日志仅移除终端输出的行尾填充空格，原始输出SHA-256另存raw_log_sha256。所有取证源码与实现提交逐一比对一致。服务端文件仍逐一匹配cb02a67的162项回归记录，没有把旧服务端运行冒充本次原生联调。

`LibraryRepository.createPackReader` 创建绑定当前连接、连接代次及阅读元数据代次的句柄，公开isCurrent供阅读会话判断归属。打开、进度、位置、偏好与默认都是不可变的类型化命令，包含原request_id及版本；submit只发送一次，receipt只读查询，未知回执返回null而不补发。写入字段由adapter统一编码。

8项用例通过受控HTTP服务检查：完整搜索/目录/标签交集/未读/来源/排序、27项范围末项与分页队列、500页清单尾页、同源鉴权与内容版本、读取不确认opened、进度/会话/偏好版本字段、丢失响应后回执读回无额外POST、原视频轮次不变、各类畸形范围/清单/回执与外域/错误版本地址拒绝、图包页/队列独立取消、换服务旧句柄拒绝、目录失效不扩大查询、401结束共享连接。

恢复用例走现有repository的真实restoreBackup通知路径：恢复待确认时不允许新建句柄或提交旧阅读写入；恢复发布新管理数据前，递增阅读代次并取消全部旧句柄。即使连接对象不变，迟到页读取仍拒绝，旧句柄不可再读/写，新的句柄可用。这个服务是协议夹具，故意模拟完成的恢复回执；它证明客户端生命周期接线，不证明真实v2备份数据、其他图包/标签旧读取范围或跨恢复批次写入已经验收。

过程记录：最初一项用例误认为连接已有协议夹具时视频轮次应为空；改为记录既有视频轮次并断言阅读操作后保持一致。没有删除隔离断言。类型匹配及风格检查修正后，最终179项和analyze重新通过。
