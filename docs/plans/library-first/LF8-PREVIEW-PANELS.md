## 本段差异

- 原控制条把播放、拖动轨道、时间和速度强制放在48dp单行。360宽/双倍字号组件检查复现131dp横向溢出（组件使用测试默认字形；真实Android另取证，不把该数值冒充原生溢出）。现在按实际文字宽度保留至少88dp轨道，不够时将时间/速度分行；字号保持，横向全屏入口跟随控制条实际高度上移。短横屏中央播放圆钮曾被控制条遮住；空间足够时向可用区调整，不足60dp时收起这个重复入口，仍保留完整可点的控制条播放按钮。
- 原范围面板固定来源、顺序和说明，只有队列滚动；很长来源与短窗口组合会挤掉队列。现在只固定标题/关闭，来源、顺序、队列和说明共用一个滚动区；保留48项读取/最多4页缓存、原重排命令及选择后关闭。按正文真实高度和字体行高定位当前项，第一项保留顶部说明；窗口/字号变化后重新定位，不创建新范围。
- 范围说明补方向、时长、文件类型。保留服务现有10秒分类口径，不能只改成原型15秒而让标签与实际范围含义不同。
- 视频更多菜单补原型已有的浅/暗色切换，复用本机偏好保存和失败反馈；不更改当前候选、默认播放顺序或当前视频。范围页码用14dp衬线，保留至少44dp触控；空筛选补“全部视频”，最近补“最近看过的视频”。快速整理大字省去重复状态文案，为两个完整动作让出空间。

## 验证与边界

组件从真实入口打开预览、整理显隐、范围、关闭和返回；四种视口/字号另查长来源滚动、当前定位、原会话/成员和实际选择。播放平台组件用于观察控件状态，不能替代真实解码。

原生使用隔离8768真实服务与公开2视频/4包/24PNG。搜索进入单项→返回筛选→完整范围，实际暂停/拖进度/速度选择/按住2倍及松手恢复；再检查整理显隐、标签取消、更多/详情、主题切换恢复、顺序队列、最后一条/结束返回和最近。截图与播放状态分别核对，普通三轮、大字和短横屏按相同源码重复；视觉按同一冻结参考独立存量评审，不打分。

本段不以短视频夹具声称完整后台/全屏设备手势矩阵、长包4K/8K、目标手机/NAS或覆盖升级已完成。源文件字节、固定候选/序号、没有标签/删除写入、来源返回和设备配置恢复必须另核对。只操作本任务可丢弃数据，不操作正式8760/NAS或发布APK。最终结果补台账及GitHub #33/#24，完整LF8仍开放。
