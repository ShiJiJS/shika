# 快速整理精简与沉浸阅读

对应 [#177](https://github.com/ShiJiJS/shika/issues/177)，依据用户在第29版截图中圈出的区域调整，仅修改客户端。

- 快速整理删除图片页码滑杆、上一张/下一张、阅读方式行及标签/回收站大按钮，底部只留下原图包范围导航。阅读方式保留在顶部更多菜单中。
- 回收站改为图片区域右下角的小型圆形悬浮按钮，沉浸时仍可操作。横屏快速整理的上下栏不再覆盖图片区域，避免导航栏遮住悬浮按钮。
- 单击图片隐藏或显示上下栏；单指向上滑动结束后隐藏上下栏。观察原始指针事件，不加入缩放/滚动的手势竞争；双指操作和横向翻页不触发上滑隐藏。
- 继续使用原有后台逻辑回收，移除后进入下一个图包仍保持沉浸。点击图片或系统返回可重新显示栏，缩放时系统返回先复位缩放。
- 普通阅读保留原有滑杆和工具区。独立原型、服务端和实际媒体文件均未改动。

验证：Flutter analyze无问题，集中44项相关测试通过。其中新增8项覆盖两种阅读方式、普通/双倍字体、竖屏和短横屏，使用实际图片解码、触摸、缩放及延迟回执，检查按钮位置、可点击性、阅读位置保持和沉浸下移除。此次未重跑此前851项整版测试，也未进行实体手机试用，不合并累计计数。

安装包升级为 `0.2.0-preview.24+30`；正常/同号回退包均通过构建、签名、包名和版本核验，无集成测试插件或原型资产；已交付NAS并回读摘要一致。见[第30版安装记录](../../nas-app-preview-2026-11-02-code30.md)。持续开发目标及其他验收仍保持暂停。
