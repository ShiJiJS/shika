# LF7 原图永久删除清单与逐页结果

承接 PR #54 的待实施审计，补齐 BAK-03、SET-05 和 DEL-04/06 的历史读取部分。本阶段新增 `management_purge_history` 只读能力，生产 `backup_v2` 仍关闭。原型保持 `design-lf-2026-10-23` 的独立目录和相同 Git 树。

## 历史身份与查询

从统一任务列表取得 historical、task ID、kind 和 graph ID。`HistoricalPurgeCatalog.purgeHistory(task)` 为这一个原任务建立 `PurgeHistoryDetails`；只有 review、images、steps 和取消读取，没有 prepare/submit/retry/undo/acknowledge。连接/管理数据变化使网关失效，晚到响应不能继续刷新页面。已返回的原计划身份不能漂移；文件读取只能使用当前已读取页里的原成员。

新增三个认证 GET，均须明确原 graph 或能精确解析的原 epoch：

| 路径（前缀 `/api/v1/management-history/tasks/{identity}`） | 返回 |
| --- | --- |
| `/purge-review` | 原计划摘要、总计及图包成员分页，默认24条 |
| `/purge-review/files?trash_id=...` | 所属原图包的精确文件分页，默认100条 |
| `/purge-pages?kind=...&outcome=...` | 原永久删除任务的图片/目录结果，默认24条 |

分页上限100，offset须为0到SQLite有符号整数上限之前。缺原图/父任务/计划/成员返回404；缺 graph、错误 epoch/graph 组合或筛选返回422。原清单未完成与原 manifest 类型/数量不符明确返回409，不能生成清单或退回当前数据。

原父任务必须在指定图中，种类只能为 pack_purge_preview 或 pack_permanent。后者还须关联该图的永久删除操作、唯一 execution 和原预览计划；文件须属于这个原计划的 trash成员。原计划始终 ready=false，保留原摘要与过期时间不赋予执行能力。成员名称、路径、文件和逐页错误全部来自同一图，不把当前索引投影或重扫后的名称套到旧记录上。

底层以 SQLite 只读 immutable 连接查标量。成员/页结果 SQL LIMIT/OFFSET；精确文件用 json_array_length/json_each 在 SQLite 里截页，不把整个 manifest JSON 加载到 Python。实际读取仍保留历史文件摘要核验，因此这不是恒定磁盘 I/O 或 NAS 性能承诺。

已有当前 `/pack-purge-plans`、`/pack-operations/.../pages` 语义保留给当前操作，历史页面不使用它们。旧服务未声明新能力时说明升级后再读取；没有原 graph 的旧历史只能保留摘要，不承诺补回从未保存的细项。

## 页面与原型约束

意图：给已有任务详情补齐历史结果，视觉严格沿用已确认 Paper 设置/任务页面。用户要核对“当时确认了哪些图片、哪些已删、哪些失败”，产出是原清单和原逐项状态；不增加新的管理对象或删除流程。

现有习惯是先找到任务，再查看原结果；长列表全高度，短确认才用底部面板。本段沿用任务详情入口、23号衬线标题/共享颜色和 IconButton、20像素任务页内容边距、ChoiceChip/分页语法，以及 MaterialPageRoute 的前进返回、筛选选中反馈、加载条三类既有动效。不更换视觉方向，不在底部增加假系统手势条。

从设置起：操作任务→历史筛选→原任务→查看逐项图片结果，共4次点击进入原结果。原来没有这个可完成的历史页面入口。清单和逐项结果在同一原任务内切换，原图包再打开精确图片页；不要求用户记 graph、复制任务编号或重新选择当前图包。

历史结果默认未完成，可切全部和图片/目录；清单24包分页，单包100文件分页。长名称/路径自然换行，列表惰性构建。目录根项保留真实路径 `.`，界面显示“图包根目录”，与命名子目录区分。返回逐级恢复原任务和来源。只读提示说明旧失败不会继续执行；不显示确认永久删除、重试原任务或结算按钮。

删除统计显示“已删除/原图片总数”；pages_pending_reconciliation只表示结果待核对，不能当作全部未删除图片。原错误区分失败与尚未完成，权限错误用中文保留含义。失败的下一页不替换旧页，固定顶部错误条可见；再次点击同一个分页入口只重试原 GET，不生成新命令。连接失效时隐藏旧列表并提示返回重新打开。
