# 继续核查：纵向部分可见页的跳过

PR #56 已验证“当前页已定位到末张”后的失败跳过与末尾操作。不能据此覆盖纵向视口里同时可见两张图片时的全部情况。

下一条可执行检查：以普通390×844纵向阅读，恢复到倒数第二张的约80%位置，让失败末张的跳过按钮进入视口；直接点击该可见按钮，检查实际路由是否到达末尾、原进度是否仍指向真正显示过的图片、且未自动换包。测试不能先调用 ensureVisible 把末张移到视口顶部，否则会改变需核查的条件。

源码依据：`_VerticalReaderState.report()` 按视口顶部确定 session.index；`picture()` 的跳过目标按所点图片的下标计算；`jump(total)` 当前还要求 session.index 已是末张。由此存在两者下标不同的可能，尚需实际行为复现，不能仅凭当前五项测试宣称该组合通过。若复现，导航应按用户明确点中的图片推进，仍须保留首帧才能写入阅读的约束。

完成这条定向检查后继续整体原型对照；连接/恢复/迟到图片、完整暗色/横屏/手势、500页4K/8K及目标手机/NAS范围仍按总验收表推进。本文件是当前证据的明确边界与下一步，不是新功能或完成声明。
