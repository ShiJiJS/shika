# 物理归档分类与标签分开

**状态：已撤销。** 原型试用时用户明确纠正：不需要独立的归档分类；未来可根据已有标签一键调整文件夹。目录整理已移出第一阶段，多标签对应唯一物理目录的规则留待后续决定，不是当前开发的阻塞项。以下保留为历史记录，不再作为实现依据。最新范围见需求文档与后续事项记录。

一个视频可以有多个标签，而用户希望离开 App 后仍能通过 NAS 文件夹方便查找，因此将决定物理目录的归档分类与标签分开。标签用于多维筛选，每个归档分类对应用户指定的目录；首次接入保留现有文件位置，之后只有用户主动执行归档才移动，执行前展示目标路径。这样无需把多个标签强行映射成唯一目录或复制多份原文件，代价是需要单独维护归档分类。

用户还会通过外部工具管理文件，因此接受外部移动后的新位置，不自动搬回归档目录；移入另一个已配置分类的目录时更新归档分类。
