## 配套服务与数据

完整媒体库、图包和独立标签需要新版服务。连接原旧服务时沿用旧视频界面，可能自动播放，不会凭 App 升级获得图包接口。 正常code16实际连接原版0.1.4服务后的首页菜单已补[普通/减少动画与返回新版核对](plans/library-first/LF8-LEGACY-HOME-MENU.md)，不代表所有旧服务版本或目标NAS已验收。新版服务尚未部署到你的 NAS。

本轮服务生产树未改，沿用 `video-viewer-server:0.2.0-preview.2`，源码 `b79da7b9c4d2ab099c055b8eb855904e32abb0a5`，镜像 ID `sha256:886b79b72ecb9116087d892f230471943121f24ccef093113cc3197b4607fef4`。现有归档为 Linux ARM64，已只读核对实际 NAS 的 ARM64 架构、旧服务和真实图包路径；部署方案已备妥但尚待明确授权，实际配置仍须在部署前复核，按[开发环境说明](macos-development.md)部署，不能当作通用 NAS 包。

服务升级前停机并完整备份实际绑定的 `data` 目录，包含 WAL 等文件。回退服务时停止新服务，在原绑定目录内恢复完整旧快照，容器内核对数据库版本、完整性与 SHA 后再启动旧镜像；旧二进制不能直接读取迁移后的数据库，恢复旧快照会舍弃升级后的管理修改。App 回退与服务数据回退分别处理。管理备份不包含媒体原文件。

切换 App 前在新版完成或核对管理任务。旧界面保留但不能接管新版 v2 备份任务；回新版核对原请求，避免重复提交。三轮服务回退、原 Windows 升级、原型移除及大图性能的既有证据继续有效，见[逐项记录](plans/library-first/RESULTS.md)；本轮没有重做未受影响的压力实验。
