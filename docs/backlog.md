# 后续事项

## 按标签一键整理文件夹

状态：用户明确移出第一阶段，待第一版体验稳定后再考虑。它不阻塞当前原型、客户端、服务端或联调任务。

希望在打好标签后，通过一次主动操作调整 NAS 上的物理文件夹，方便离开 App 后查找。不维护另一套归档分类，修改标签本身不移动文件。

一个视频有多个标签时如何决定唯一目标目录尚未确定；不预设标签顺序、目录层级或标签组合规则，不为此复制视频。后续做这一功能前再对齐映射规则、预览和冲突处理。

当前的「快速整理模式」用于筛选、连续查看、打标签及删除撤销，不包含上述目录调整。第一版仍支持原有目录浏览、外部改名/移动后的同步，以及回收站操作。
