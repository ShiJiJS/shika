# Flutter 客户端演示验收

当前范围：D1 和 C1–C6 的演示客户端，P2 已获用户确认并关闭。真实服务端与分功能联调尚未开始；C6 的最终用户试用确认仍保留。

## 运行条件

沿用既有 Flutter 3.47.7、Android API 36 的 `video_viewer_api_36` 模拟器和 VS Code F5 配置。使用软件图形、关闭 Vulkan、冷启动，没有重新搭建环境。播放器为 Android 的真实媒体插件，素材来自打包的 MP4 文件。

## 自动验证

- 静态分析通过，8 条本地数据/组件流程连续 3 轮通过。覆盖组合筛选和批量标签重开读回、标签改名/删除、幂等删除与精确撤销、写入失败回滚、备份校验/恢复/目录映射、外部变化及根目录可用性、恢复冲突和新增轮次、连接输入错误保留。结果见 `client-evidence/local-run-1.txt` 至 `local-run-3.txt`。
- 5 条 Android 原生完整流程连续 3 轮通过，共 15 条结果。覆盖真实播放/拖进度/倍速/滑动回看/横屏返回、标签与目录组合和重开、快速整理删除撤销及备份文件恢复、目录异常/外部变化，以及连接失败/空库恢复。结果见 `client-evidence/integration-run-1.txt` 至 `integration-run-3.txt`。最后补充的活动标签删除轮次规则由上述本地数据检查连续 3 轮复验，随后重新构建普通演示入口。
- 集成测试的数据存储与备份文件使用 App 临时目录，和用户试用的演示状态隔离。文件桥接注入隔离备份文件，验证实际文件读写、替换确认与恢复。
- 普通演示 App 另经 Android 原生 DocumentsUI 实查：导出到 Downloads 后读回有效 JSON（8 个视频、5 个标签、无 connection 字段）；再通过原生选择器选入同一文件，进入校验通过的映射和替换确认面板，取消后返回。实际画面见 `native-save.png`、`native-import-preview.png`；没有把测试桥接冒充原生文件选择器验证。

## 实际画面与设计

`client-evidence/` 保存 Android 屏幕的实际截图。浏览页继续采用紧凑的标题/位置、目录/播放模式/更多三个按钮、视频下方快捷标签和四项底栏；快速整理时才增加管理操作。Android 正文使用系统无衬线字体，页名和内容名称使用随附的 Noto Serif SC 子集，沿用纸白与草木绿。

面板沿用 240ms 展开/收起，导航指示 160ms；标签采用原生点击反馈。移除计数器、默认紫色主题和环境验证文案，没有增加归档分类或按标签移动文件夹。

独立评审按存量界面迁移标准对比 P2 与 5 张实际 Android 截图，不打分。确认颜色、宋体页名、视频主区、模式专属操作条和面板层级延续原型，未发现必须修正的遮挡、裁切或系统栏冲突。原生截图不适用 Web 截图工具的 lint；没有伪造 Web 检查报告，也没有把画面评审当成功能复验。

## 验证中修正

- 成功通知与删除撤销提示原先会遮住底栏；改为明确的底部导航区域，浏览提示避开标签与快速操作条，可连续删除和导航。
- 底栏移入 Scaffold 导航区域后，收紧其高度，避免容器扩张挤压视频。
- 表单控制器在弹层完全退出后才释放，防止关闭动画和键盘变化触发已释放控制器的异常。
- 界面注入不同数据提供方时重建对应页面状态，避免测试或后续提供方切换继承旧页面状态。
- 删除正在用于筛选的标签时重建已放宽范围的轮次，标签改名保留原关联和文件位置。

## 播放交互试用反馈（2026-10-16）

纵向分页替代原先松手后直接换片的手势：视频跟随手指移动，短拖回弹，落定后保存轮次，写入失败时滑回原条目。相邻页预载播放器并以封面衔接，只有当前条目播放；顶栏、快捷标签与导航保持原位。

移除暂停画面的中央播放图标，保留点画面暂停/继续和底部进度控制。播放中长按临时 2 倍速，顶部仅显示小型反馈；松手、系统取消指针或切到后台恢复原速度。横屏沿用同一手势与播放器。

3 条专项 Android 流程连续 3 轮通过，覆盖跟手位移、短拖回弹、前后切换、首尾边界、新轮次、保存失败退回、暂停无中央按钮、暂停时长按不自动播放、1/1.5 倍速的长按恢复、指针取消和横屏后台恢复。运行记录与实际画面存于 `client-evidence/player-*`，未以静态画面代替手势验证。

既有真实播放流程也连续 3 轮通过，复查进度拖动、菜单倍速、连续向前一条/向后一条与横屏返回。测试辅助点击仅在目标不可见时滚动，避免强制对齐已在视频内可见的控件而带动分页。长按恢复另外监听原始指针取消事件，覆盖框架取消手势时不触发长按结束回调的情况。静态分析无问题。

已查看普通演示 App 的实际 Android 截图：`player-paused.png` 中央无图标，`player-hold.png` 仅在视频顶部提示倍速，`player-drag.png` 显示相邻两页的纵向交接。标签和底栏未被遮挡。本次沿用现有样式定点修改，未另做独立视觉评审。

## 本阶段的边界
