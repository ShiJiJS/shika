App、服务和`design/reference`逐文件与固定阶段提交`c9c6363a`一致，主分支9份CLI文件与`b690f508`一致；仅文档的历史证据链接及整体入口作了整理。第27版客户端实际构建来源为`0b1ec622`，服务preview.8实际来源为`2de02374`；整合没有重新生成安装包、改动已部署服务或访问NAS数据。

复用既有验证：服务534项、客户端第27版41项相关检查，以及正常/同号回退包的分析、构建和原签名校验。它们各自的版本和范围见原记录；源码一致性不替代实体手机、性能或完整45项验收，不把累计测试数当成整版通过。
