# 与当前客户端的功能对照

依据：当前工作区 `apps/mobile/pubspec.yaml` 为 0.1.4+5，Mac 迁移记录说明它与 Windows 原 0.1.4 同源。逐项读取 `apps/mobile/lib/ui/home.dart` 的 settings/connection/roots/trash/backup，`preferences.dart`、`paper.dart`，并交叉核对 `docs/v1-spec.md`。这是源码功能对照，未声称本轮操作了用户手机上的安装包。

| 当前客户端能力 | 上轮原型 | 判断与本轮处理 |
| --- | --- | --- |
| 暗黑模式，设置与更多入口同步、本机保存 | 遗漏 | 补回，沿用客户端暗色调色板；不进入管理备份 |
| 准备相邻视频，最多前后各一条 | 遗漏 | 补回开关并本机保存；真实解码/预加载仍由现有 Flutter 播放器承担 |
| 默认随机/顺序 | 只有预览内本轮顺序 | 补回全局默认，新范围生效；本轮切换仍在预览内 |
| 服务地址、端口、个人口令、错误保留输入 | 简化成 URL 保存 | 补回完整表单与连接失败状态；口令不落原型持久化存储、不进入备份 |
| 目录添加、编辑、真实挂载路径 | 仅两个类型开关 | 补回名称、路径、类型、启停；类型扩展到图包 |
| 扫描包含子目录、手动同步、进度 | 遗漏 | 补回同步与进度、失败状态和任务记录 |
| 缺失记录、标签保留、清除失效记录 | 遗漏 | 补回缺失列表、原路径和确认；离线目录记录不会被清除 |
| 回收站全选、批量恢复、永久删除 | 仅单项恢复 | 补回，视频/图包分开；永久删除说明不可逆、整包含所有图片 |
| 文件操作结果待确认与查询 | 遗漏 | 统一放操作任务，并保留处理/失败/待确认状态；查询原任务而非重复提交 |
| 管理备份导出、格式检查、统计预览 | 只有基本 JSON 导入导出 | 补充完整数据范围和校验错误，显示两套标签、目录、回收站统计 |
| 恢复目录映射、替换确认、恢复前快照 | 遗漏 | 补回映射表、明确确认、旧数据快照和回看入口；不恢复已永久删除对象 |
| 图包阅读默认设置 | 新增，已有基本模式 | 保留并补默认方向、图片间距，已阅读图包继续使用各自偏好 |
| 标签搜索 | 遗漏 | 补回当前类型内搜索，不跨视频/图包 |
| 视频参数与原路径详情、横向全屏入口 | 遗漏 | 补回到预览更多与画面控件，不放入设置 |
| 更多/媒体库中的整理、筛选、标签管理 | 已迁入新入口 | 保留；与媒体库中心结构兼容，不新增重复设置入口 |
| 暂停、倍速、长按临时 2 倍、跟手翻页、亮度与音量手势 | 原型仅呈现部分播放行为 | 这些仍是现有播放器的必要行为，不废弃；本轮不重写 Flutter 播放器或在设置新增无依据开关。原型中的逐帧手势、硬件音量/亮度不作为此次设置验收范围 |
| 调试构建的演示场景 | 未放入 | 仅 kDebugMode 且 DemoControls 下出现，不放进日常设置 |
| 无限缓存、自适应预取、自动清空回收站 | 当前正式客户端也没有 | 不凭空增加；相邻预加载与永久删除已覆盖现有控制需求 |

## 边界

本轮只更新 HTML 交互原型；没有连接真实 NAS、提交扫描、验证真实口令或删除源文件。连接、扫描、任务状态使用本机模型呈现交互；目录的新增路径不会加载 NAS 内容。永久删除只把样例条目放入原型的不可恢复集合。真实文件删除、服务器备份校验和任务重试可靠性沿用正式接口，在实施阶段对接验证。

界面使用真实产品文案，模拟边界集中记录于本文与 README。状态地址支持 `?state=connection/roots/missing/trash/backup/tasks/dark`；失败场景为 `scenario=connection-failure/scan-failure/operation-pending/storage-failure`。

## 设置结构

连接与文件（服务连接、媒体目录）；数据维护（回收站、备份与恢复、操作任务）；偏好（暗黑、相邻视频准备、播放顺序、图包阅读偏好）。延用客户端的分组行、15px 行标题、紧凑图标与 P2 尺寸，移除占位 NAS 大卡片。长管理页面用全高度面板，编辑和确认仍使用底部面板。

## 验证结果

设置 8 组流程连续 3 轮通过，另通过 4 组失败/结果待确认场景；原有 12 组主流程及 5 组图包整理流程各 3 轮通过。包括刷新后的真实持久化读回、备份文件内容检查、确认前不执行恢复、两类标签搜索隔离。独立截图评审一轮未发现具体问题；真实 NAS 操作及原生播放器能力不属于原型测试结论。
